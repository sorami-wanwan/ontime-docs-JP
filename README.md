# Ontime 日本語公式ドキュメント（ontime-docs-JP）

このリポジトリは、ライブイベント・放送・配信向けタイムキーピング＆進行表管理ツール「**Ontime**」の日本語フォーク版（[ontime-JP](https://github.com/sorami-wanwan/ontime-JP)）向け公式日本語マニュアルおよびドキュメントサイトです。

> [!NOTE]
> **本プロジェクト（ontime-JP / ontime-docs-JP）について**
> 本リポジトリは、Carlos Valente 氏が主導するオープンソースプロジェクト [Ontime](https://github.com/cpvalente/ontime)（GPL v3）をベースに、個人（sorami）が**日本語 UI の完全ローカライズ**および**日本語 IME（日本語入力）利用時の最適化・不具合修正**を行って再構築したコミュニティフォークプロジェクトです。

- **日本語フォーク版リポジトリ**: [sorami-wanwan/ontime-JP](https://github.com/sorami-wanwan/ontime-JP)
- **日本語ドキュメントリポジトリ**: [sorami-wanwan/ontime-docs-JP](https://github.com/sorami-wanwan/ontime-docs-JP)
- **オリジナル公式（英語版）リポジトリ**: [cpvalente/ontime](https://github.com/cpvalente/ontime)
- **オリジナル公式サイト**: [https://www.getontime.no](https://www.getontime.no)

# コントリビューション（貢献）

Ontime はコミュニティ主導のオープンソースプロジェクトであり、皆様からの貢献を歓迎しています。 \
