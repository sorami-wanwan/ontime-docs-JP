## Ontime Cloud を選ぶ理由

Ontime Cloud は、Ontime をオンライン環境で最も素早く立ち上げて利用できる方法です。

事前準備（プリプロダクション）期間や、現地の専用ネットワークインフラを構築するのが難しい現場でも、いつでも Ontime を活用できます。

Ontime は引き続き完全なオープンソースであり、ローカルでのセルフホストも可能です。 \
データは完全なポータビリティを保っており、Cloud 版とローカル版の間でいつでも自由に移行できます。

## 料金プラン

Ontime Cloud では、ユーザーのニーズに合わせた2つのプランを提供しています。

### Ontime Cloud PRO

Ontime Cloud PRO は、個人や小規模チーム向けの標準クラウドプランです。

固定枠数のステージ（インスタンス）を提供し、コラボレーター（共同作業者）の人数制限やシート単位の課金はありません。短期利用から定期的な運用まで柔軟に利用できるように設計されています。

PRO は以下のような用途に最適です：
- 複雑なセットアップなしで Ontime をオンラインで運用したい
- サーバーインフラの管理をせずにチームでコラボレーションしたい
- 長期の縛りなく、予測しやすい料金で利用したい

:::tip[割引対象について]
教育機関、非営利団体（NPO）、または予算に制約のあるプロジェクトについては割引が適用できる場合があります。 \
[お気軽にお問い合わせください！ (mail@getontime.no)](mailto:mail@getontime.no)
:::

### Ontime Cloud STUDIO

Ontime Cloud STUDIO は、**より多くのステージ数や高いリソース制限** を必要とするチーム向けのプランです。

Studio は PRO やローカル環境と全く同じ Ontime ソフトウェアを実行します。 \
違いは機能ではなく、ステージの収容力と運用規模にあります。

多数のショー、複数のホール、複数の会場を同時並行で運営し、自社でホスティングインフラを管理したくない組織に最適です。

さらに、Studio プランでは以下のような **オプションの Cloud 拡張** をリクエストできます：
- カスタムドメイン
- バニティ URL（専用の分かりやすい短縮 URL）
- 特別なルーティングやカスタムデプロイ調整

これらの拡張はご要望ごとに個別設計され、Studio サブスクリプションとは別料金となります。

Studio の料金は利用要件およびオプション拡張の内容に応じて決定されます。

サインアップ時にプランを選択でき、後からプランを変更することも可能です。
