Ontime Cloud にサインアップすると、ダッシュボードにアクセスしてステージ、チーム、サブスクリプションを管理できるようになります。

## チームの管理

![Dashboard stages](../../../assets/ontime-cloud/dashboard-team.png)

Ontime のサブスクリプションはチームに紐づいています。

サインアップしたユーザーが「アカウントオーナー（所有者）」となり、アカウント情報や全設定へのアクセス権を持ちます。

また、他のメンバーをアカウントに招待することもできます。招待されたユーザーは、権限に応じた範囲で同じダッシュボードにアクセスできます。

:::note
ステージの URL 自体はパブリック（誰でも閲覧可能）です。
単にステージ画面を見たり操作したりするだけであれば、チームメンバーとして招待する必要はありません。

チームへの招待は、アカウントやステージ自体の管理（起動・停止・設定など）を行わせたいスタッフに対してのみ実施してください。
:::

### アカウント種別
Ontime Cloud には現在 2 種類のアカウント権限があります：

- **Member (メンバー)** – ステージの管理（起動や停止など）が可能です。 \
現場の技術スタッフやオペレーターには通常この権限を付与します。
- **Owner (オーナー)** – サブスクリプション管理やアカウント削除を含むすべての操作が可能です。 \
また、新しいメンバーをチームに招待することもできます。

### サブスクリプションの管理
Ontime Cloud PRO は月額サブスクリプションサービスです。

決済およびサブスクリプションの管理には Stripe を利用しています。 \
`Team` タブ内の `Manage subscription`（サブスクリプションの管理）ボタンをクリックすると、以下の操作が行える専用ポータルに移動します：
- 支払い方法の更新・変更
- 請求先情報の変更
- 過去の領収書（レシート）のダウンロード
- サブスクリプションの解約

:::note[サブスクリプションの解約]
Ontime のサブスクリプションはいつでも解約できます。 \
解約手続きを行っても、現在の請求サイクルの終了日までは引き続きプランのすべての機能をご利用いただけます。
:::
