### 「ステージ (Stage)」とは何ですか？

**Ontime Cloud PRO** サブスクリプションでは、標準で 3 つのステージが提供されます。 \
ステージとは、個別の Ontime インスタンスを実行できるスロット（枠）のことです。

つまり、ステージごとに 1 つずつ、最大 3 つの異なるプロジェクトを同時に実行できます。 \
すべてのステージは完全に分離されており、個別のプロジェクトデータ、パスワード、権限、設定を持っています。

### 自身の PC にインストールする Ontime と Ontime Cloud の違いは何ですか？

Ontime はサーバーアプリケーションです。 \
Ontime Cloud は、サーバー管理、ネットワーク設定、アップデート作業を行うことなく、オンライン上で即座に実行できる Ontime のマネージドホスティングサービスです。

自身で Ontime をローカルホストする場合、サーバーを起動し、ネットワークに公開して共同作業者がアクセスできるように維持・管理する必要があります。 \
これは管理されたローカル環境では適していますが、複数拠点での作業、外部チームとの連携、あるいは本番直前の限られた時間の中では手間がかかる場合があります。

Ontime Cloud はサーバーのセットアップ作業を不要にし、安定した安全な URL を通じて、必要な時にいつでもアクセスできる環境を提供します。 \
実行されている Ontime ソフトウェア自体の機能は全く同じです。

### プロジェクトに何人まで共同作業者を招待できますか？

**人数制限はありません！**

Ontime はチーム全員が活用することで最大の価値を発揮すると考えています。 \
Ontime ではシート数やユーザー数に応じた課金は一切行っておらず、今後も行う予定はありません。

### Ontime Cloud で Companion を使用できますか？

**はい、使用できます！**

Ontime Cloud はローカルの Ontime と同じ [HTTP および WebSocket API](/api/) をサポートしているため、簡単に接続先を切り替えられます。 \
Bitfocus Companion の Ontime モジュールも通常通り動作します。

Companion から Ontime Cloud への接続方法については、[Companion モジュールのガイド](/additional-notes/companion-module/#companion-から-ontime-への接続設定) を参照してください。


### STUDIO プランのユーザーはカスタムの Cloud 設定を依頼できますか？

**はい、可能です！**

Studio プランのお客様向けに、一般的な機能としては提供されない以下のような Cloud レベルの個別設定を承っています：

- カスタムドメイン
- バニティ URL（専用の分かりやすい短縮 URL）
- 特定のルーティングやデプロイ構成の個別カスタマイズ

これらのご要望はオプションの Cloud 拡張として対応し、要件定義の上で Studio サブスクリプションとは個別にお見積もりいたします。 \
（※実現可能性や要件のスコープにより対応可否を判断いたします）
