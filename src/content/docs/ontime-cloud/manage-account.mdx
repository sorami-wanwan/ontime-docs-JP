Ontime Cloud にサインアップすると、ダッシュボードにアクセスしてステージ、チーム、サブスクリプションを管理できるようになります。

## アカウントの管理

![Account dashboard](../../../assets/ontime-cloud/dashboard-account.png)

チーム内での役割（権限）にかかわらず、すべてのユーザーが自身のアカウントを管理できます。

ここでは以下の操作が可能です：
- プロフィール情報の更新
- パスワードの設定および変更
- 認証アプリ（Authenticator）の連携（詳細は [認証アプリ連携のTips](/ontime-cloud/tips/login-with-auth/) を参照）
- アカウントの削除

:::note
Ontime Cloud の初期バージョンでは、ログインにワンタイムパスワード（OTP）のみをサポートしていました。 \
アカウントにまだパスワードを設定していない場合は、この画面からパスワードを設定できます。
:::

### アカウントの削除
アカウントはいつでも削除できます。

チームのオーナーであり、有効なサブスクリプション契約がある場合は、アカウントを削除する前に必ずサブスクリプションを解約してください。

アカウントを削除すると、Ontime のシステムからユーザー情報およびコンテナデータが完全に削除されるようにスケジュールされます。
