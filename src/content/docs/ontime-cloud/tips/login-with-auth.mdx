Ontime では、ログイン認証の管理に TOTP（Time-based One Time Password：時間ベースのワンタイムパスワード）を使用しています。

## TOTP によるログイン

![Dashboard stages](../../../../assets/ontime-cloud/feat-sync-with-auth.png)

Ontime Cloud ユーザーは、ログイン時やアカウント情報の変更時に TOTP を利用します。 \
これにより、特に複数のユーザーで共有されるアカウントにおいて、安全で便利な認証手段が提供されます。

このプロセスをさらに簡単にするために、Ontime Cloud アカウントを各種認証アプリ（Authy、Google Authenticator、または各種パスワードマネージャーなど）と同期できます。

同期手順はとてもシンプルです。ログイン後、`Accounts` タブに移動します：
1. 表示された QR コードをお好みの認証アプリでスキャンします
2. 認証アプリが生成した 6 桁の確認コードを Ontime に入力して検証します

設定はこれだけで完了です！

同期完了後は、メールの受信を待つことなく認証アプリのワンタイムコードを使って Ontime Cloud にすばやくログインできるようになります。 \
（※確認用のメールコードも並行して送信されます）
