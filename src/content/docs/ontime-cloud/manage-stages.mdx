Ontime Cloud にサインアップすると、ダッシュボードにアクセスしてステージ、チーム、サブスクリプションを管理できるようになります。

## ステージの管理

![Dashboard stages](../../../assets/ontime-cloud/dashboard-stages.png)

Ontime Cloud PRO サブスクリプションでは、最大 3 つのステージを同時に管理できます。 \
各ステージは独立した個別の Ontime インスタンスです。ステージはいつでも起動（Start）および停止（Stop）できます。

ステージを起動すると、そのステージ専用の固有な恒久リンク（URL）が生成されます。 \
このリンクはパブリックにアクセス可能で、URL を知っている人なら誰でもその Ontime ステージにアクセスできます。

リンクはステージが存在する限り予約されたまま維持されるため、リハーサルや本番セッションの合間に安全に停止させ、後で同じ URL で再開することができます。 \
プロジェクトが完全に終了したらステージを削除（Delete）してリンクを解放できます。次回新しくステージを作成した際には新しい URL が生成されます。

:::note[Ontime のバージョン]
ステージを新規作成すると、その時点で最新の Ontime バージョンで起動します。

本番運用の安定性を保ち、予期せぬトラブルを防ぐため、稼働中のステージが自動でバージョン更新されることはありません。 \
ステージをアップデートしたい場合は、一度ステージを停止し、`Upgrade version`（バージョンのアップグレード）アクションを実行してください。

ステージ停止中もデータが失われることはありませんが、一時的にリンクへはアクセスできなくなります。
:::

### ステージのライフサイクル操作
- **Start (開始)** – 最新バージョンの Ontime でステージを作成・起動し、パブリックリンクを予約します。
- **Stop (停止)** – リンクを一時的にアクセス不可にします。設定の変更、バージョンのアップグレード、またはデータを維持したまま一定期間アクセスさせたくない場合に使用します。停止してもステージ内のデータは保持されます。
- **Delete (削除)** – パブリックリンクとステージ内の全データを完全に削除します。この操作は取り消せません。

### タイムゾーン (Timezone)
ステージごとに個別のタイムゾーンを設定できます。

ドロップダウンメニューから主要なタイムゾーンを選択できるほか、任意の IANA タイムゾーン（例: `Asia/Tokyo` や `Europe/Oslo`）を直接指定することもできます。 \
タイムゾーン一覧は [Wikipedia (IANA タイムゾーン一覧)](https://en.wikipedia.org/wiki/List_of_tz_database_time_zones) を参照してください。

### パスワード
Ontime では、制作画面（エディタ、オペレーター、キューシート）を PIN コードで保護することができます。

さらに強力なアクセス制御を行いたい場合は、Ontime Cloud のダッシュボードからステージ全体にアクセスパスワードを設定することも可能です。

パスワードを設定しない場合、リンクを知っているすべてのユーザーがステージにアクセスできます。 \
パスワードを変更する場合は、ステージを一度停止して再起動する必要があります。
