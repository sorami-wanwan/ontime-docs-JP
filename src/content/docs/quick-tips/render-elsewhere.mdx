---
title: 外部アプリでのビュー描画
description: OBS、vMix、disguise、TouchDesigner 等で Ontime ビューを表示
---

Ontime の各種出力ビューは、ネットワーク経由で Web ページを描画できる任意の外部アプリケーション（OBS Studio、vMix、disguise、TouchDesigner など）にそのまま取り込んで表示できます。

:::note[背景色、カラーキー、透過設定]
`timer`（ステージタイマー）ビューでは、`key` オプションを使用して背景色や透過色（クロマキー・アルファチャンネル）を自由に指定できます。 \
詳しくは [ビューのカスタマイズ](/quick-tips/configuring-views/) をご覧ください。

明示的な `key` オプションがないビューでも、[カスタム CSS 上書き](/features/custom-styling/) を利用して背景色を変更できます：

```css
:root {
  --background-color-override: #00ff00; /* グリーンスクリーン用 */
}
```
:::

### 実例: OBS Studio でプロンプター・返りモニターを表示

![Lower thirds in OBS](../../../assets/screenshots/features/obs-confidence-monitor.png)

OBS Studio の **ブラウザソース (Browser Source)** を使用して、Ontime のステージタイマー画面を取り込み、配信画面のワイプやマルチビュー画面として活用できます。

OBS に Ontime の URL（例: `http://<IPアドレス>:4001/timer`）を入力するだけで、リアルタイムなタイマーが描画されます。

:::note[Ontime Cloud でパスワード保護されたステージの場合]
Ontime Cloud でパスワードが設定されているステージを利用する場合は、認証情報を含んだ共有リンクを生成して OBS に貼り付けます：

1. `エディタ` -> `設定` -> `共有とレポート` -> `リンクを共有` を開きます
2. 目的のビューまたはプリセットを選択し、**認証を含める** のトグルをオンにします
3. **共有リンクを作成** をクリックしてコピーした URL を OBS のブラウザソースに設定します
:::

### 外部アプリでの描画トラブルシューティング

Ontime は幅広いブラウザ環境に対応していますが、一部の古い CEF（Chromium Embedded Framework）を内蔵した古いメディアサーバーや配信ソフトウェアでは、画面が真っ白になり正常に描画されない場合があります。

その場合、Ontime の WebSocket データを直接受信してシンプルな HTML で描画する [カスタムビュー](/features/custom-views/) を作成することで、古い環境にも柔軟に対応できます。
