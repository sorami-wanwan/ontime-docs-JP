Ontime のほとんどのビュー画面は、URL クエリパラメーターを使って柔軟に表示をカスタマイズできます。 \
（※[エディタ](/interface/production/app-editor/) ビューおよび [キューシート](/interface/production/cuesheet/) ビューを除く）

![Configure Ontime view](../../../assets/screenshots/features/timer__params.png)

各端末専用にカスタマイズした URL リンクを作成して共有できるため、[URLプリセット機能](/features/url-presets/) と組み合わせると非常に便利です。

各ビュー画面の右上に表示される **設定（歯車アイコン）** をクリックすると、ビューパラメーターエディタ（上記画像）が開き、GUI 上で直感的に表示要素のオン/オフやレイアウトを調整できます。

## 時刻フォーマットの設定
Ontime の時計表示はデフォルトで **24時間表記**（例: `15:10:10`）です。 \
**アプリケーション設定** でデフォルトを **12時間表記**（例: `03:10:10 PM`）に変更できます。

さらに、一部のビューでは補助時刻（スケジュール時刻や時計）の表示形式を個別にカスタマイズできます：

| 指定フォーマット      | 表示結果                                        | 
| :-------------------- | :---------------------------------------------- |
| `HH:mm:ss`            | `15:10:10`     (24時間表記のデフォルト)        |
| `hh:mm:ss a`          | `03:10:10 PM`  (12時間表記のデフォルト)        |
| `HH:mm`               | `15:10`                                         |
