## イベントの時刻構成

Ontime の各イベントは、`開始時刻 (Start time)`、`終了時刻 (End time)`、`所要時間 (Duration)` という 3 つの時刻フィールドを持っています。

あるイベントの開始時刻は、[前のイベントの終了時刻とリンク](#開始リンク-link-start) させることができます。

また、`所要時間 = 終了時刻 - 開始時刻` という関係があるため、3つのうち2つが決まれば残り1つは自動計算されます。 \
Ontime では、どの値を優先して維持するかを決める [時間戦略 (Time strategy)](#時間戦略-time-strategy) を自由に設定できます。

これらの機能を組み合わせることで、スケジュールの一部が変更された際に、以降のすべてのイベントへ変更を自動伝播させることができます。

![Link and lock times](../../../assets/screenshots/features/rundown__lock-times.png)

### 開始リンク (Link start)
あるイベントの開始時刻を、直前のイベントの終了時刻と自動同期（リンク）させることができます。

`開始時刻` 入力欄の横にある鍵アイコンをクリックして有効化します（*上記画像の注釈 1 を参照*）。 \
有効にすると、前のイベントの終了時刻が変更された場合、このイベントの開始時刻も自動的に追従して更新されます。

※これは進行表の計画上の連動設定です。実際の再生開始を手動ではなく自動で行いたい場合は、直前イベントの `終了アクション (End Action)`（`次を再生 (Play Next)` など）を使用します。

### 時間戦略 (Time strategy)
イベントの時間計算において、「所要時間」と「終了時刻」のどちらを固定（ロック）するかを決定します。

デフォルトでは `所要時間 (Duration)` がロックされます（デフォルトは `エディタ` -> `プロジェクト設定` -> `進行表のデフォルト設定` で変更可能）。

各イベント行の入力欄横の鍵アイコンをクリックして、イベントごとにロック対象を切り替えることができます（*注釈 2: 終了時刻ロック、注釈 3: 所要時間ロック*）。

上記画像の進行表の例で、1つ目のイベント（Albania）の終了時刻が延びた場合：
- 2つ目のイベント（Latvia）が **所要時間ロック** の場合：所要時間を維持するため、終了時刻が後ろ倒しになります。
- もし **終了時刻ロック** の場合：指定された終了予定時刻を守るため、所要時間が短縮されます。

## 時間入力ショートカット
Ontime のすべての時間入力フィールドでは、コロンやゼロを省略した素早い入力が可能です：

| 入力例                                  | 変換結果                                                | 説明 / ルール                                                                                            |
| :-------------------------------------- | :------------------------------------------------------ | :------------------------------------------------------------------------------------------------------- |
| `1.20.3` `1 20 3` `1:20:03` `1,20,3`    | `01:20:03`                                              | `.` `,` `:` および `スペース` を区切り文字として使用可能                                                |
| `1.2.3` `1 2 3` `1:2:3` `1,2,3`         | `01:02:03`                                              | 3つの数字は `時間:分:秒` として認識                                                                      |
| `1.2` `1 2` `1:2`                       | `01:02:00`                                              | 2つの数字は `時間:分` として認識                                                                         |
| `10`                                    | `00:10:00`                                              | 1つの数字（99以下）は `分` として認識                                                                    |
| `120`                                   | `01:20:00`                                              | 3桁以上の数字（100以上）は `時間` と `分` に自動分割                                                     |
| `1h30s`                                 | `01:00:30`                                              | `h` `m` `s` を使って特定の単位を直接指定                                                                 |
| `120m`                                  | `02:00:00`                                              | 単位指定時は桁あふれも自動計算（120分 -> 2時間）                                                         |
| `p`                                     | `09:00:00` (直前イベント終了が 09:00:00 の場合)         | キーワード `p` で直前イベントの終了時刻を自動代入                                                        |
| `+10m10s`                               | `09:10:10` (直前イベント終了が 09:00:00 の場合)         | 先頭に `+` を付けると、直前イベントの終了時刻に時間を加算                                               |
| `2.2.2` `2 2 2` `2:2:2` `2,2,2`         | `02:02:02`                                              | 先頭のゼロ（0）は省略可能                                                                                |
| `10:` または `:10`                      | `10:00:00` または `00:10:00`                            | 区切り記号を使って省略位置を指定可能                                                                     |
| `123456`                                | `12:34:56`                                              | 6桁入力で区切りなしの `hhmmss` として認識（※5桁以下の場合は分として扱われます）                           |
