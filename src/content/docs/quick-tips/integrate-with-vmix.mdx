## vMix から Ontime を制御する
vMix から Ontime を操作する最もシンプルな方法は、Ontime の [HTTP API](/api/protocols/http/) を利用することです。 \
vMix のスクリプト機能を使って、Ontime の再生・停止・ロードなどを簡単にトリガーできます。

設定手順（vMix の Scripting 機能を使用）：
- vMix の `Settings` -> `Scripting` を開き、`Add` をクリックします
- 以下の VB.NET スクリプトを貼り付けて `Save` をクリックします

```vb
' Ontime の指定 ID（例: 4b044）のイベントを開始する GET リクエスト
Dim client = WebRequest.Create("http://<localhost:4001>/api/start/id/<4b044>")
Dim response = client.GetResponse()
```

:::note
スクリプト内の `<localhost:4001>` は Ontime が動作しているマシンの IP アドレスおよびポート番号に、`<4b044>` は Ontime のエディタ画面で確認できる対象イベントの ID に置き換えてください。

利用可能なすべてのエンドポイントは [HTTP API ドキュメント](/api/protocols/http/) で確認できます。
:::

作成したスクリプトは、vMix のショートカットキーやトリガーに自由に割り当てることができます。

## Ontime から vMix を制御する（テロップ自動更新など）

Ontime の [オートメーション機能](/api/automation/) を使用して、イベントのロード時や開始時に vMix の API へ HTTP リクエストを送信し、vMix 側のテロップ（タイトル）文字列などを自動更新できます。

以下は、Ontime でイベントがスタンバイ（ロード）されるたびに、vMix のタイトル入力にある **Headline.Text** フィールドを現在イベントのタイトルに自動更新する例です：

1. Ontime の `エディタ` -> `設定` -> `オートメーション` を開きます
2. **オートメーションの管理** で新規作成し、出力タイプに `HTTP` を選択して以下の URL を設定します：

```bash
http://127.0.0.1:8088/api/?Function=SetText&Input=Title%201&Value={{eventNow.title}}&SelectedName=Headline.Text
```

3. **トリガーの管理** で新しいトリガーを作成します
4. ライフサイクルトリガーに `On Load` を選択します
5. 割り当てるオートメーションに、先ほど作成したオートメーションを選択して保存します

:::note
上記の URL では、[オートメーションの変数機能](/api/automation/#オートメーションでの変数の使用)（`{{eventNow.title}}`）を使用して動的にタイトルを代入しています。 \
IP アドレスやポート（vMix の Web Controller ポート: デフォルト 8088）、タイトル入力名（`Title 1`）はご自身の環境に合わせて変更してください。
:::
