作成した進行表や設定データはすべてユーザー自身のものです。 \
Ontime では、プロジェクトファイルの書き出し・読み込みや、他ツールへのエクスポート機能が充実しています。

ローカル PC で動作している Ontime と Ontime Cloud サービスの間でデータを移動する際にも、同じファイル形式で簡単に行き来できます。

## Ontime プロジェクトファイルの書き出し / 読み込み

### プロジェクトファイルのエクスポート
`エディタ` -> `プロジェクト` -> `プロジェクト管理` から、プロジェクトファイルをエクスポートできます。 \
プロジェクトファイルは、進行表やアプリケーションの全設定を含む `JSON` 形式のファイルです。

### プロジェクトファイルのインポート
他のユーザーと共有されたプロジェクトファイルやバックアップファイルを、`エディタ` -> `プロジェクト` -> `プロジェクト管理` からインポートできます。

また、インポートしたプロジェクトから特定の設定や進行表のみを現在のプロジェクトに取り込む **部分読み込み（Partial Load）** 機能も備わっています。 \
複数のプロジェクト間で共通のプリセットや設定を再利用したい場合に最適です。

## スプレッドシートへの進行表エクスポート
進行表データを Excel やスプレッドシート形式で書き出したい場合：

`エディタ` -> `プロジェクト設定` -> `進行表の管理` を開き、オーバーフローメニュー（3点リーダー）から **.xlsx をダウンロード** をクリックします。 \
また、[Google スプレッドシート連携](/features/import-spreadsheet-gsheet/) を使用して直接アップロード・ダウンロードすることも可能です。

### スプレッドシートからの進行表インポート
Excel、Numbers、Google スプレッドシート等で作成した `.xlsx` / `.csv` ファイルから進行表をインポートできます。

詳しくは [スプレッドシートからのインポート](/features/import-spreadsheet/) および [Google スプレッドシート連携ガイド](/features/import-spreadsheet-gsheet/) をご覧ください。
