---
title: ロールモード (Roll Mode)
description: Ontime を現在時刻に追従させて自動完全自走させる再生モード
---

**ロールモード (Roll)** は、現在のシステム実時刻（時計）に合わせて、Ontime を完全自動で自走させるプレイバックモードです。 \
単独での自動運用はもちろん、手動再生と組み合わせて「特定の時間帯だけ自動進行させる」といった運用が可能です。

:::note[活用例]
- 12:00 - 17:00 -> 会場設営・リハーサル
- 17:00 - 19:00 -> 夕食休憩
- 19:00 - 19:30 -> 開場（客入れ）
- 19:30 - 20:00 -> オープニングアクト
- 20:00 - 20:10 -> メインアクト

コンサートやカンファレンスなどでは、開場前や転換中などオペレーターが常駐していない時間帯があります。 \
その間はロールモードで自動的に各スケジュールに追従させ、本番開始時に手動操作に切り替えて厳密なタイムキーピングを行う、といった柔軟な運用が可能です。
:::

### 基本動作
- 進行表内にスキップされていない有効なイベントが存在する限り、ロールモードを有効化できます。
- 現在の実時刻に該当するイベントがない場合、直近の次のイベントを自動でロードし、その開始時刻に向けてカウントダウンします。
- 現在時刻に該当するイベントが複数ある場合は最初の一致イベントがロードされます。
- 現在のイベントが終了すると、自動的に次のイベントをロードしてカウントダウンを継続します。

### 手動再生からロールモードへの切り替え
手動再生からロールモードに切り替えた場合、再生はそのまま自動モードへと移行します。 \
以下の点にご注意ください：
- 現在のイベントが超過時間（オーバータイム）に入っている場合、ロールモードへの移行は無効化されます。
- ロールモードは、切り替え時点のオフセット（遅延・進み）を維持して後続イベントの開始/終了時刻を計算します。
