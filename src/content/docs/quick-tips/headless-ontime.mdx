---
title: ヘッドレス（GUIなし）での Ontime 実行
description: ディスプレイやGUIのない環境（CLI / Docker）で Ontime を実行
---

Ontime はヘッドレス（CLI または Docker）ディストリビューションを利用して、画面のないサーバー環境でも実行できます。 \
会場の設備常設サーバー、Raspberry Pi、クラウドの VPS サーバーなどでの運用に最適です。

ヘッドレス実行は、Ontime を最も軽量かつ柔軟にデプロイできる方法です。

## NPM による実行 (CLI)

### はじめに

#### 前提条件
適切なバージョンの **Node.js** がインストールされている必要があります。 \
必要な Node.js バージョンは [リポジトリ内の package.json](https://github.com/cpvalente/ontime/blob/master/package.json) をご確認ください。

#### Ontime のインストールと起動
パッケージマネージャーを使用してグローバルにインストールします：

システム全体にグローバルインストール：
```bash
npm install -g @getontime/cli
```

インストールしたコマンドを実行：
```bash
ontime
```

または、一時的に実行する場合（npx）：
```bash
npx @getontime/cli
```

起動後、同一ネットワーク内の任意のデバイスからブラウザでアクセスできます（デフォルトポート: 4001）。

## Docker による実行

### はじめに

マシンに Docker をインストールします（各 OS や Raspberry Pi の公式ガイドを参照）。

Docker インストール後、[Docker Hub](https://hub.docker.com/r/getontime/ontime) から Ontime のイメージを取得します：

```bash
docker pull getontime/ontime
```

### docker-compose による起動

以下のような `docker-compose.yml` ファイルを作成します：

```yaml
version: "3"

services:
  ontime:
    container_name: ontime
    image: getontime/ontime:latest
    ports:
      - "4001:4001/tcp"
      - "8888:8888/udp"
      - "9999:9999/udp"
    volumes:
      - "./ontime-data:/data/"
    environment:
      - TZ=Asia/Tokyo
    restart: unless-stopped
```

起動コマンド：
```bash
docker-compose up -d
```

### 設定内容の解説

* `4001:4001/tcp`: Web UI 用のポートマッピング。ブラウザからアクセスするために必須です。
* `8888:8888/udp`: OSC 受信用のデフォルトポート。外部機器やホストマシンから Ontime への OSC 入力に使用します。
* `9999:9999/udp`: OSC 送信用のデフォルトポート。Ontime から外部機器への OSC 送信に使用します。
* `"./ontime-data:/data/"`: プロジェクトや設定ファイルを永続化するためのボリュームマウント。
* `TZ=Asia/Tokyo`: コンテナのタイムゾーン（日本標準時）設定。

### よくある質問（FAQ）🚨

#### Ontime のデフォルトポート
Ontime はデフォルトでポート 4001 で Web サーバーを起動します。 \
Docker のポート設定を `80:4001/tcp` に変更すると、標準の HTTP ポート（80番）で公開できるため、URL にポート番号を指定せずにアクセスできます（例: `http://<IPアドレス>/editor`）。

#### ボリューム（データの保存先）
コンテナ内部の主要ディレクトリ：
- `/data/projects/`: プロジェクトファイルの保存先
- `/data/styles/`: カスタム CSS 上書きファイルの保存先
- `/data/external/`: 外部アセット・カスタムビューの配信フォルダ

個別にマウントすることも可能です：
```yaml
    volumes:
      - "./ontime-projects:/data/projects/"
      - "./ontime-styles:/data/styles/"
      - "./ontime-external:/data/external/"
```

#### コンテナの時刻・タイムゾーン設定
Docker コンテナはデフォルトで UTC タイムゾーンで動作します。環境変数 `TZ=Asia/Tokyo` を指定して適切なタイムゾーンを設定してください。

#### 画面は表示されるがタイマーが動かない場合
Ontime は時刻データを WebSockets 経由でブラウザにストリーミング配信しています。 \
リバースプロキシ（NGINX、Caddy、Traefik など）や Synology NAS の背後で運用する場合、プロキシ側で WebSocket の転送（`Upgrade` / `Connection` ヘッダーのパススルー）が正しく設定されているかご確認ください。
