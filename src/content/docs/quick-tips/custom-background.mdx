---
title: カスタム背景画像の設定
description: Ontime の各ビューに独自の背景画像を設定する方法
---

Ontime には背景画像を選択する標準の UI 設定はありませんが、[CSS 上書き機能](/features/custom-styling/) を利用することで、任意のカスタム背景画像を簡単に適用できます。

大まかな手順は以下の通りです：
- Ontime の配信フォルダ（`external`）に背景画像を配置
- CSS を上書きして、目的の画面の背景にその画像を指定

![Custom background in timer](../../../assets/screenshots/features/custom-bg.png)

具体的な設定手順は以下の通りです：

## 1. Ontime に画像を配置する
Ontime の内蔵 Web サーバー機能を利用して画像を配信します。

### external フォルダの場所を確認する
お使いの OS に応じて、Ontime のデータ保存場所にある `external` フォルダを確認します：

**Windows の場合:**\
`AppData/Roaming/Ontime/external/`

**macOS の場合:**\
`Library/Application Support/Ontime/external/`

**Linux の場合:**\
`Home/Ontime/styles/external/`

:::tip[パスを素早く確認する]
`エディタ` -> `設定` -> `ビュー設定` で CSS 上書き機能を有効化すると、CSS 上書きファイルの保存先フルパスが表示されます。その親フォルダまたは同階層に `external` フォルダが存在します。
:::

### 画像ファイルの追加
`external` フォルダ内に `images` フォルダを作成し、背景に使用したい画像（例: `bg.png`）を保存します。

## 2. CSS を上書きする
CSS 上書きを行うには、以下の 2 つが必要です：
1. 上書き対象となる画面要素の CSS セレクタ
2. CSS 上書きファイルの編集

### CSS セレクタの取得
ブラウザの開発者ツール（F12 キーまたは右クリック -> 「検証」）を開き、背景を適用したいコンテナ要素を特定します。 \
要素を右クリックして `Copy` -> `Copy selector`（セレクタをコピー）を選択します。

ステージタイマー画面の場合、例えば `#root > div.App > div.stage-timer` というセレクタが取得できます。

### CSS の記述
CSS 上書きファイルに、先ほど取得したセレクタを使って背景画像を指定します：

```css
#root > div.App > div.stage-timer {
  background-image: url('/external/images/bg.png');
  background-size: cover;
}
```

### CSS 上書きの有効化
`エディタ` -> `設定` -> `ビュー設定` で **カスタム CSS を有効化** のトグルをオンにします。

これで、ブラウザで `/timer` 画面を開くと、設定したカスタム背景画像が表示されるようになります。
