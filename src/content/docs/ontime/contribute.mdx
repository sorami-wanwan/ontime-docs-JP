title: 貢献する (Contribute)
description: Ontime プロジェクトへの貢献
---

Ontime はコミュニティ主導のプロジェクトであり、あらゆる貢献を歓迎しています。 \
改善のアイデアや新機能についてディスカッションしませんか？

[**メール (mail@getontime.no)**](mailto:mail@getontime.no) や [Discord サーバー](https://discord.com/invite/eje3CSUEXm)、[Subreddit](https://www.reddit.com/r/ontimeapp/) へお気軽にご参加ください。日本語版フォークへのフィードバックや PR は [ontime-JP リポジトリ](https://github.com/sorami-wanwan/ontime-JP) でも受け付けています。

コードの貢献をご検討いただける開発者の方は、Pull Request を作成する前にまず Issue を作成して議論していただくことを推奨しています。

Ontime の開発に初めて参加される方向けに、[Good First Issue](https://github.com/cpvalente/ontime/issues?q=is%3Aopen+is%3Aissue+label%3A%22good+first+issue%22) ラベルの付いたタスクを用意しています。 \
これらは全体のアーキテクチャに詳しくなくても着手しやすいタスクです。 \
開発環境のセットアップ方法については、[開発ドキュメント (DEVELOPMENT.md)](https://github.com/cpvalente/ontime/blob/master/DEVELOPMENT.md) を参照してください。
