:::note[日本語フォークプロジェクト（ontime-JP）について]
本ドキュメントおよび **ontime-JP** は、Carlos Valente 氏が主導するオープンソースプロジェクト [Ontime](https://github.com/cpvalente/ontime)（公式サイト: [www.getontime.no](https://www.getontime.no)）をベースに、個人（sorami）が日本語環境での実用性を高めるために独自にフォーク・再構築した非公式コミュニティプロジェクトです。

**主なフォーク改良点：**
- **日本語 UI の完全ローカライズ**: エディタ、キューシート、オペレーター画面、各種タイマー画面の日本語化
- **日本語 IME 入力の最適化**: 日本語入力（IME）確定時の意図しないショートカットキー発火や文字化け・フォーカス不具合の解消
- **完全な日本語ドキュメントの整備**: 全機能、各種 API、外部連携（OBS、vMix、Companion 等）の日本語マニュアル提供

プロジェクトのソースコードは [GitHub (sorami-wanwan/ontime-JP)](https://github.com/sorami-wanwan/ontime-JP) で公開されています。
:::

## <mark>進行表（ランダウン）</mark>と<mark>イベントタイマー</mark>を管理するオープンソースソフトウェア

:::tip[Ontime とは]

Ontime は、進行表（ランダウン）の管理、スケジュール追跡、キュー出しを行うブラウザベースのアプリケーションです。 \
リアルタイムコラボレーションと強力な外部連携により、ライブ制作、放送、各種イベントを強力にサポートします。

Ontime はリアルタイムでのチーム連携、直前の変更対応、スムーズな情報共有を可能にし、制作ワークフローを効率化します。

Ontime は場所を選ばずどこでも実行できます： \
お使いの PC にインストールしたり、制作現場のローカルネットワークやクラウド上で動作させることができます。

詳細については公式サイト [www.getontime.no](https://www.getontime.no) をご覧ください。
:::
