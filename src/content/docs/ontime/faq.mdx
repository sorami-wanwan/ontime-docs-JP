## 古い Intel Mac でも Ontime を実行できますか？
はい、利用可能です！ Ontime は Apple Silicon 用と Intel (x64) プロセッサ用のビルドを個別に提供しています。お使いの Mac の環境に合わせたバージョンをダウンロードしてください。 \
ダウンロードリンクは [ontime-JP リリース](https://github.com/sorami-wanwan/ontime-JP/releases) または [公式サイト](https://www.getontime.no/) から入手できます。

## どの Linux バージョンを選べばよいですか？
Ontime は CPU アーキテクチャに合わせて複数の Linux パッケージを提供しています。
- **一般的な PC / デスクトップ (x86_64)**: [64-bit AppImage (x86_64)](https://github.com/sorami-wanwan/ontime-JP/releases/latest/download/ontime-linux-x86_64.AppImage) をダウンロード
- **Raspberry Pi 4 以降 (64-bit ARM)**: [Arm 64-bit AppImage (arm64)](https://github.com/sorami-wanwan/ontime-JP/releases/latest/download/ontime-linux-arm64.AppImage) をダウンロード
- **古い Raspberry Pi (32-bit ARM)**: [Arm 32-bit AppImage (armv7l)](https://github.com/sorami-wanwan/ontime-JP/releases/latest/download/ontime-linux-armv7l.AppImage) をダウンロード

## Ontime をシャットダウンするには？
デスクトップアプリとして実行している場合、Ontime のウィンドウを閉じるだけではサーバープロセスは停止しません。 \
これは誤操作による不意のシャットダウンを防ぐための安全設計です。

Ontime を完全にシャットダウンするには、`エディタ` -> `設定` -> `シャットダウン` を選択してください。

:::note
Ontime のシャットダウンは、アプリを実行しているローカルマシンからのみ実行できます。 \
実行中のマシン上で操作しているにもかかわらずボタンが無効化されて警告が表示される場合は、ブラウザで `localhost` アドレスを使用するか、アプリのウィンドウ内から操作してください。
:::
