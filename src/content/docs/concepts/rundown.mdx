Ontime では、イベントの進行表（ランダウン / スケジュール）を作成して管理できます。 \
入力されたスケジュール情報から一連のタイマーが自動生成され、予定時刻からの遅延や進み具合をショーディレクター、舞台監督、オペレーターにリアルタイムでフィードバックします。

:::note[進行表（ランダウン）とは？]
Ontime における「ランダウン (Rundown)」とは、放送・イベント業界で一般的に使われる用語で、番組やイベント内の各セグメントとその時間配分を順番に並べた進行表のことです。

事前準備（プリプロダクション）段階では「割り当て時間内に収まるか」の計画作成に用いられ、本番（ランタイム）ではイベントを予定通りスムーズに進行させるために活用されます。
:::

## Ontime での進行表作成

進行表を作成するための主な画面は、Ontime 起動時に表示される [エディタ (Editor)](/interface/production/app-editor/) 画面です。

エディタは本番中のランタイム制御も行いますが、計画段階では並べ替え、複製、スキップなどの操作を直感的に行い、すばやく進行表を構築できる豊富なツールを提供します。

:::tip[シンプルなステージタイマーとして使いたい場合]
Ontime はシンプルな用途から大規模で複雑なイベントまで柔軟に対応します。 \
高度な進行表オフセットやメタデータを使わず、単にステージタイマー（例: 1分、5分、10分のカウントダウン）として使いたいだけの場合でも、手軽にイベントを作成してタイマーとして再生できます。
:::

## タイマーエントリとメタデータエントリ

Ontime の進行表には、大きく分けて **タイマーエントリ** と **メタデータエントリ** の 2 種類のエントリを登録できます：

- **タイマーエントリ (Timer events)**: Ontime がカウントダウンや計測を行うタイマーを生成するエントリ
- **メタデータエントリ (Metadata events)**: タイマーを生成せず、進行表に情報や注記を整理・追加するためのエントリ

### イベント (Events)

![Rundown event](../../../assets/screenshots/editor/rundown/docs_event.png)

**概要**: 登壇者のプレゼンテーション、動画再生、音楽演奏など、個々のショーセグメントを表します。

イベントはタイマーを生成する主要な進行表エントリです。 \
Ontime でイベントを再生（プレイバック）すると、対応するステージタイマーや各種配信ビューに情報が表示されます。

また、イベントの所要時間を積算することで、進行表全体やグループ全体の合計所要時間やスケジュールを算出できます。

詳細な時間入力の仕様については、[スマートな時間入力のクイックTips](/quick-tips/smart-time-entry/) をご覧ください。

### グループ (Groups)

![Rundown event](../../../assets/screenshots/editor/rundown/docs_group.png)

**概要**: パネルディスカッションの全登壇者や、第1幕の全シーンなど、関連する複数のエントリをまとめることができます。

グループは複数のエントリを束ねるメタデータエントリです。 \
グループ自体は固有のスケジュールを持ちませんが、内部に含まれるイベントのスケジュールを自動的に継承・集計します。

グループを活用することで、進行表をセクションごとに構造化し、まとまったエントリの移動や複製を一括で行えます。

また、Ontime はグループ終了予定時刻や終了見込み時刻までのカウントダウンタイマーも自動生成できます。

### マイルストーン (Milestones)

![Rundown event](../../../assets/screenshots/editor/rundown/docs_milestone.png)

**概要**: 「特効・花火スタンバイ」「舞台転換の進捗確認」など、オペレーター向けの重要メモを挟み込みます。

マイルストーンは進行表内のメモ用エントリです。 \
オペレーターへの指示出しや注意点を進行表の特定のタイミングに挿入できます。 \
マイルストーンはスケジュール時間を持たず、一般向けのスケジュールビュー（バックステージビューなど）には表示されません。

## ディレイ（遅延）エントリ

![Rundown event](../../../assets/screenshots/editor/rundown/docs_delay.png)

ディレイエントリは、Ontime の遅延管理システムの中核機能です。

スケジュールの変更や遅延が発生した際、ディレイエントリを使ってチーム全体に最新の予定変更を伝達できます。 \
ディレイは元のスケジュールの上にオーバーレイとして適用され、各ビューに分かりやすく視覚化されます。 \
詳しくは [遅延の管理](/quick-tips/managing-delays/) をご覧ください。

## 進行表の共有

ショーディレクターや Ontime オペレーターは主に [エディタ (Editor)](/interface/production/app-editor/) 画面で作業します。

しかし、Ontime の真の強みはチーム間のコラボレーションにあります。

[キューシート (Cuesheet)](/interface/production/cuesheet/) ビューや [オペレーター (Operator)](/interface/production/operator/) ビューは、チームメンバーがリアルタイムで情報共有・編集を行うために設計されています。 \
進行表を作成したら共有リンクを発行することで、他部署のスタッフが進行を確認したり、各自の担当データを直接入力したりできます。

### エクスポート

印刷やアーカイブ用途で進行表を出力したい場合は、[Excel エクスポート](/quick-tips/import-export/) や [Google スプレッドシート連携](/features/import-spreadsheet-gsheet/) を活用してください。

Ontime 自体には直接の印刷レイアウト機能はありませんが、Excel 形式でエクスポートすることで、現場の好みのレイアウトやフォントで印刷・共有できます。
