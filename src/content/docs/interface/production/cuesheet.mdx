```bash title="キューシート"
https://cloud.getontime.no/my-stage/cuesheet           
```

<mark>キューシート (Cuesheet)</mark> は、部門を越えたリアルタイムの共同作業のために設計されたテーブル形式のビューです。

チームメンバーや他部署のスタッフは、キューシートを使って本番の進行状況をフォローしながら、[カスタムフィールド](/features/custom-fields/) を使って各自の担当データ（音響キュー、照明キュー、スライド番号、登壇者情報など）を入力・管理できます。

列ごとにきめ細かな読み取り・書き込み権限を設定できるため、クライアントや外部スタッフと進行表を共有・共同編集する際にも非常に便利です。 \
特定の列のみ編集可能にしたり、閲覧専用に制限することで、安全な共同作業を実現します。
