<mark>エディタ (Editor)</mark> 画面は、Ontime のメインとなる管理・操作画面です。

ここでは、進行表（ランダウン）の作成・編集・再生（プレイバック）制御のほか、アプリケーション全体のすべての設定パネルにアクセスできます。
