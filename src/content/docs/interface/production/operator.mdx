<mark>オペレーター (Operator)</mark> ビューは、現場で進行を追うオペレーターのために設計されています。 \
スマートフォンやタブレットなどの小型端末に最適化され、極力手動操作を減らして画面に集中できるよう作られています。

オペレータービューは再生中の進行に自動追従し、必要に応じてデータ入力も可能です。 \
タイトルやメモ、任意の [カスタムフィールド](/features/custom-fields/) を選択して表示をカスタマイズできるため、各オペレーターが各自の担当業務に最も必要な情報だけを強調して確認できます。
