## 利用可能なビュー一覧

Ontime は、目的に応じて進行表データを閲覧・編集できる多様なインターフェースを提供しています：

- [制作ビュー (Production views)](#制作ビュー-production-views): 進行表の編集や情報入力が可能なインタラクティブな画面。詳細な進行管理やチームでの協調作業に適しています。
- [自動配信ビュー (Automated views)](#自動配信ビュー-automated-views): 閲覧専用（ノンインタラクティブ）のディスプレイ画面。本番中の確認や部署間連携のために、進行表の重要情報を分かりやすく表示します。

同じローカルネットワーク内にあるブラウザ搭載デバイスから、Ontime が動作しているマシンの IP アドレスとポート番号を指定して各ビューにアクセスできます。例:
```
http://<IPアドレス:ポート番号>/editor -> http://192.168.10.1:4001/editor
```

:::note
すべてのビューはカスタマイズ可能で、表示項目や動作を自由に設定できます。 \
自動配信ビューの設定内容は URL パラメーターに保持されるため、ブックマークや共有も簡単に行えます。

詳しくは [ビューの設定クイックTips](/quick-tips/configuring-views/) をご覧ください。
:::

### 制作ビュー (Production views)

データの入力や操作が可能な画面で、主にディレクター、舞台監督、オペレーターなどが使用します。

| URL                                             | ドキュメント                                |
| :---------------------------------------------- | :----------------------------------------- |
| `https://cloud.getontime.no/my-stage/editor`    | [エディタ (Editor)](/interface/production/app-editor/) |
| `https://cloud.getontime.no/my-stage/cuesheet`  | [キューシート (Cuesheet)](/interface/production/cuesheet/) |
| `https://cloud.getontime.no/my-stage/op`        | [オペレーター (Operator)](/interface/production/operator/) |

### 自動配信ビュー (Automated views)

進行表データを様々なレイアウトで自動表示する閲覧専用画面です。 \
初期設定後はユーザー操作を行わずにサイネージやモニターとして無人運用できます。

| URL                                              | ドキュメント                                         |
| :----------------------------------------------- | :-------------------------------------------------- |
| `https://cloud.getontime.no/my-stage/timer`      | [ステージタイマー (Timer)](/interface/automated/stage-timer/)           |
| `https://cloud.getontime.no/my-stage/timeline`   | [タイムライン (Timeline)](/interface/automated/timeline/)           |
| `https://cloud.getontime.no/my-stage/backstage`  | [バックステージ (Backstage)](/interface/automated/backstage/)    |
| `https://cloud.getontime.no/my-stage/countdown`  | [カウントダウン (Countdown)](/interface/automated/countdown/)         |
| `https://cloud.getontime.no/my-stage/studio`     | [スタジオクロック (Studio Clock)](/interface/automated/studio-clock/)   |
