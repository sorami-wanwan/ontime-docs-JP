<mark>ステージタイマー (Stage Timer)</mark> は、ステージ上の登壇者や出演者に向けて設置されるコンフィデンスモニター（返しモニター）用のビューです。

現在進行中のスピーカーに対する残り時間を大きく見やすく表示します。 \
また、現在および次のセグメント（イベント）に関する情報も表示されます。

![Ontime](../../../../assets/screenshots/views/4-timer.png)

エディタ画面からステージタイマーの表示内容を詳細にカスタマイズでき、[外部連携データやメッセージ（サブメッセージ）](/features/secondary-message/)、全画面メッセージ、[AUXタイマー（補助タイマー）](/features/aux-timer/) などを表示させることができます。 \
動画の再生残り時間や別セッションまでのカウントダウンなど、登壇者に必要な補足情報を柔軟に提供できます。
