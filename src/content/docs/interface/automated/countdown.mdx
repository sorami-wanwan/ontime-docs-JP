---
title: カウントダウン (Countdown)
description: 特定の予定イベントへのカウントダウンビュー
---

```bash title="カウントダウン"
https://cloud.getontime.no/my-stage/countdown           
```

<mark>カウントダウン (Countdown)</mark> ビューを使用すると、進行表の中から任意に選択した予定イベントに対する専用のカウントダウン画面を作成できます。

特定のセグメントの開始時間や残り時間だけを追跡したい場合に最適です。 \
例: 休憩時間のみを追跡したいケータリング・運営スタッフや、自分の登場シーンまでの時間だけを確認したい出演者など、他のイベント情報を省いて目的の時間のみを大きく提示できます。
