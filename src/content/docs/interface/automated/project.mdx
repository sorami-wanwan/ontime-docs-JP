<mark>プロジェクト情報 (Project Info)</mark> ビューは、現在のプロジェクトの基本情報やカスタムデータを一覧表示するシンプルな画面です。 \
進行表に直接関係しないプロジェクト全体の連絡先一覧、Wi-Fi パスワード、会場の注意事項などをクルーや関係者に共有する場所として便利です。
