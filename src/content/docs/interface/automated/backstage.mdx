<mark>バックステージ (Backstage)</mark> ビューは、実行中タイマーの概要と進行表のスケジュール一覧を同時に表示します。

舞台袖や楽屋・控室のモニター向けに設計されており、出演者や制作スタッフがイベント全体の進捗状況や次の出番の予定時刻を一目で把握できます。
