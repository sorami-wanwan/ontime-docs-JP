<mark>タイムライン (Timeline)</mark> ビューは、当日の全体の進行と今後の予定イベントを視覚的なタイムライン形式で直感的に表示します。 \
フェスティバルや複数セッションがあるイベントのバックステージ・控室モニターに最適です。
