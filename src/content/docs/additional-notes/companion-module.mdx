### Companion から Ontime への接続設定

![Network settings](../../../assets/screenshots/editor/settings/network__companion-link.png)

Companion を Ontime に接続するには、モジュール設定で Ontime サーバーのアドレスを指定します。 \
同一 PC 内であれば `localhost`、ローカルネットワーク内の他端末であればローカル IP アドレス、Ontime Cloud の場合はステージ URL を指定します。

Ontime 側で接続用のアドレスを簡単にコピーできます：
1. `エディタ` -> `設定` -> `共有とレポート` -> `リンクを共有` を開きます
2. `Ontime ビュー` で **Companion** を選択します
3. ステージがパスワード保護されている場合は、**認証を含める** のトグルをオンにします
4. **共有リンクを作成** ボタンをクリックしてアドレスをクリップボードにコピーします
5. Companion の設定画面に戻り、`Ontime server address` 欄に貼り付けます
