:::note
商用コード署名証明書の取得・維持には継続的な費用がかかるため、オープンソース版の Ontime は未署名で配布されています。 \
コード署名のスポンサー支援やアイデアをお持ちの方は、[メール (mail@getontime.no)](mailto:mail@getontime.no) または [GitHub Issue](https://github.com/cpvalente/ontime/issues) までご連絡ください。
:::

Ontime はコード署名が行われていません。 \
これはコードの品質や安全性に問題があるわけではありませんが、各 OS のセキュリティ機能によって警告ダイアログが表示される場合があります。

## Windows

Windows では SmartScreen による以下のような警告が表示される場合があります：
```
Windows によって PC が保護されました
Microsoft Defender SmartScreen は認識されないアプリの起動を停止しました。このアプリを実行すると、PC が危険にさらされる可能性があります。
```

起動を許可するには、**「詳細情報」** をクリックし、表示された **「実行」** ボタンをクリックしてください。

## Linux

Linux（AppImage 形式）で以下のようなエラーが表示される場合：
```
Could Not Display "ontime-linux.AppImage"
```
AppImage ファイルを右クリックして `プロパティ` -> `アクセス権`（Permissions）を開き、**「プログラムとして実行可能にする」**（Allow Executing File as a Program）にチェックを入れてください。
