## ネットワークの接続性
Ontime はサーバープロセスとして動作します。

Ontime が起動すると、マシンがアクセス可能なすべてのネットワークインターフェース（有線 LAN、Wi-Fi、仮想アダプターなど）で自動的に待機を開始します。 \
生成された URL リンクを現場スタッフと共有することで、同一ネットワーク内にある任意の端末（PC、タブレット、スマートフォン）からブラウザでアクセスできます。

また、外部ソフトウェアやハードウェアからの自動制御にも、これらの IP アドレスを使用します。

:::caution[注意]
他のデバイスから Ontime にアクセスできない場合は、マシンのファイアウォール設定や Wi-Fi ルーターの端末間通信制限（プライバシーセパレーターなど）をご確認ください。 \
Ontime 側の設定はサーバーポート（デフォルト: 4001）のみです。

**リバースプロキシ** の背後で動作させる場合は、WebSockets のパススルー設定（`Upgrade` ヘッダー転送）が有効になっているか必ず確認してください。
:::

### 設定画面でのネットワーク確認
`エディタ` -> `設定` -> `ネットワーク` に、現在 Ontime が利用可能なすべてのネットワークインターフェースと IP アドレスの一覧が表示されます。

![Network settings](../../../assets/screenshots/editor/settings/network.png)

### ナビゲーションメニューでの確認
Ontime を実行しているマシン本体で操作している場合、ナビゲーションメニューの最下部に外部アクセス用のリンクが表示されます。

![Network settings](../../../assets/screenshots/features/timer__nav.png)

## セキュリティに関する推奨事項
Ontime は信頼できるローカルネットワーク内での利用を前提として設計されており、**インターネットなどのパブリックなネットワークに直接公開することは推奨されません**。

`/editor`、`/cuesheet`、`/op` などの操作ビューには、**一般設定** で設定できる **PINコード** による簡易的なアクセス制限をかけることができます。

ただし、同一ネットワーク上の端末からは API を介してコマンドを送信できるため、**最も重要なセキュリティ対策はネットワーク層（VLAN 分割や専用 Wi-Fi の設定）で実施することを強く推奨します**。
