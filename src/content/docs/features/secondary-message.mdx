[ステージタイマー](/interface/automated/stage-timer/) のサブフィールド（セカンダリメッセージ領域）に、任意のテキストを表示できます。

![Timer with external data](../../../assets/screenshots/views/4-timer.png)

このメッセージはエディタ画面から手動入力できるほか、[API](#api-からのセカンダリメッセージ設定) 経由で外部ソフトウェアから自動送信することも可能です。 \
Ontime の API を活用することで、ソフトウェア間の自動連携がスムーズに行えます。

主な利用用途：
- 登壇者の邪魔にならない形で補足情報を伝える（例: 「残り時間を意識してください」「マイクに近づいてください」など）
- 他のソフトウェアから情報を表示する（例: 再生中の動画タイトルや経過時間など）

### API からのセカンダリメッセージ設定

セカンダリメッセージは、他のアプリケーションから Ontime へリアルタイムデータを送るのに最適です。 \
[OSC](/api/protocols/osc/#例-セカンダリメッセージサブメッセージのテキスト変更)、[HTTP](/api/protocols/http/#例-セカンダリメッセージサブメッセージのテキスト変更)、[WebSocket](/api/protocols/websockets/#例-セカンダリメッセージサブメッセージのテキスト変更) の各 API ドキュメントを参照してください。
