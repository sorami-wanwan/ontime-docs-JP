---
title: カスタムフィールド (Custom Fields)
description: 進行表に独自のカスタムフィールドを追加
---

カスタムフィールドを使用すると、進行表内の任意のイベントに対して独自のデータ項目を追加できます。

照明、音響、カメラ、配信など、部署やオペレーターごとの専用データを進行表に持たせるのに最適です。 \
[オペレーター](/interface/production/operator/) ビューや [キューシート](/interface/production/cuesheet/) ビューと組み合わせることで、本番中のリアルタイムな情報共有が格段に向上します。

![Custom Ontime view](../../../assets/screenshots/views/2-cuesheet.png)

:::note
カスタムフィールドは、`エディタ` -> `設定` -> `プロジェクト設定` -> `カスタムフィールド` から作成・編集できます。 \
作成したフィールドは、エディタ画面およびキューシート画面で利用可能になります。
:::
