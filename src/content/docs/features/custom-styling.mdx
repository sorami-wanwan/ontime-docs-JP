---
title: カスタムスタイリング (CSS)
description: カスタムスタイルシートを使って独自のデザインを適用
---

CSS 上書きファイルを編集することで、Ontime の各ビューのデフォルトスタイルを独自にカスタマイズできます。

この機能の有効化および CSS ファイルの編集は、`エディタ` -> `設定` -> `ビュー設定` から行えます。

## スタイル上書きに関する注意点

設定したカスタム CSS は各画面の読み込み時に同時に読み込まれます。

簡単にスタイリングできるよう、Ontime では主要な CSS カスタムプロパティ（CSS変数）を用意しています（下記参照）。 \
また、ブラウザの開発者ツールでページ要素を検証し、任意の CSS クラスを直接上書きすることも可能です。

:::tip[実際のコードを確認する]
機能追加に伴いドキュメントの記載が最新のコードと異なる場合があります。 \
最新の変数定義は [GitHub 上のサンプル CSS 定義](https://github.com/cpvalente/ontime/blob/master/apps/server/src/user/styles/bundledCss.ts) を直接ご確認ください。

実際の適用例は [カスタム背景のクイックTips](/quick-tips/custom-background/) でも紹介しています。
:::

```css
:root {
  /** ビューの背景色 */
  --background-color-override: #ececec;

  /** ビューのメイン文字色 */
  --color-override: #101010;

  /** ビューのサブ文字色 */
  --secondary-color-override: #404040;

  /** アクセント文字色（アクティブな要素に使用） */
  --accent-color-override: #fa5656;

  /** ラベル文字色 */
  --label-color-override: #6c6c6c;

  /** タイマーの文字色 */
  --timer-color-override: #202020;
  --timer-warning-color-override: #ffbc56;
  --timer-danger-color-override: #e69000;
  --timer-overtime-color-override: #fa5656;
  --timer-pending-color-override: #578AF4;

  /** カード要素の背景色 */
  --card-background-color-override: #fff;

  /** 全体のフォントファミリ */
  --font-family-override: 'Open Sans';

  /** /timer ビュー内の外部メッセージおよびAUXタイマーの文字色 */
  --external-color-override: #161616;

  /** ビュー専用設定: /backstage */
  /** ---- 点滅動作時の背景ハイライト色 */
  --card-background-color-blink-override: #339e4e;
  /** ---- プログレスバーの背景色 */
  --timer-progress-bg-override: #fff;
  /** ---- プログレスバーの進行部分の色 */
  --timer-progress-override: #202020;

  /** ビュー専用設定: /op */
  --operator-customfield-font-size-override: 1.25rem;
  --operator-running-bg-override: #339e4e;

  /** ビュー専用設定: /studio */
  --studio-active: #101010;
  --studio-idle: #cfcfcf;
  --studio-active-label: #101010;
  --studio-idle-label: #595959;
  --studio-overtime: #101010;
}
```
