Ontime では、外部で作成されたスプレッドシート（Excel または CSV、Google スプレッドシート）から進行表データをインポートできます。

![Spreadsheet template](../../../assets/screenshots/features/spreadsheet-template.png)
上記スクリーンショットの Google スプレッドシート テンプレートは [こちら][spreadsheet-link] から確認できます。

:::tip[Google スプレッドシートとの直接連携]
Google スプレッドシートから直接インポートや双方向同期を行いたい場合は、Google Cloud の認証設定を行うことで簡単に連携できます。 \
詳しくは [Google スプレッドシート連携ガイド](/features/import-spreadsheet-gsheet/) をご覧ください。
:::

## データのインポート規約

正常にインポートを行うために、以下のルールに従ってスプレッドシートを作成してください：

1. Ontime は 1 つのワークシートを読み込みます。
2. シート内に不要な列が含まれていても問題ありません。Ontime はマッピングで指定した列のみをインポートします。
3. インポート時にスプレッドシートの各列と Ontime のフィールドを対応付けます。
4. テーブルの各行が 1 つの進行表エントリとして作成されます（※タイマータイプの例外を除く）。
5. 時刻・時間は、Excel の時刻形式のほか、[スマートな時間入力](/quick-tips/smart-time-entry/) で解説している短縮文字列（例: `00:10:15` や `10m15s`）でも指定できます。

Ontime が認識する各フィールドのデータ型一覧は以下の通りです：

※列ヘッダー名は大文字小文字を区別しません（`Title` と `title` のどちらも認識されます）。

| イベントフィールド | データ型                                                                                 | デフォルト値        |
| :----------------- | :--------------------------------------------------------------------------------------- | :------------------ |
| Start (開始時刻)   | Excel 時刻 \| [文字列](/quick-tips/smart-time-entry/)                                    | 00:00:00            |
| Link start (開始リンク)| 真偽値 (boolean)                                                                      | false               |
| End (終了時刻)     | Excel 時刻 \| [文字列](/quick-tips/smart-time-entry/)                                    | 00:00:00            |
| Duration (所要時間)| Excel 時刻 \| [文字列](/quick-tips/smart-time-entry/)                                    | 00:00:00            |
| Cue (キュー)       | 文字列 (string)                                                                          | ""                  |
| Title (タイトル)   | 文字列 (string)                                                                          | ""                  |
| Skip (スキップ)    | 真偽値 (boolean)                                                                         | false               |
| Note (メモ)        | 文字列 (string)                                                                          | ""                  |
| Colour (カラー)    | 文字列 (#16進数カラーコード または [CSSカラー名][css-colour])                            | ""                  |
| End action (終了アクション)| `none` `load-next` `play-next`                                                    | `none`              |
| Timer type* (タイマータイプ)| `count-down` `count-up` `clock` `block` `skip` `group` `group-end` `milestone` `none` | `count-down`        |
| Count to end* (終了までカウント)| 真偽値 (boolean)                                                                 | false               |
| Time warning (警告時間)| Excel 時刻 \| [文字列](/quick-tips/smart-time-entry/)                                 | 00:02:00            |
| Time danger (危険時間) | Excel 時刻 \| [文字列](/quick-tips/smart-time-entry/)                                  | 00:01:00            |

:::note[タイマータイプと行のスキップ]
**Timer type** 列では、タイマーの動作タイプを指定できます。

指定可能なカウント形式: `count-down`、`count-up`、`clock`、`none`。 \
また、`block` を指定するとブロックエントリが作成されます。

上記以外の値（例: `skip` や `production` など）が入力されている行は、Ontime によってインポート対象外として自動的にスキップされます。
:::

:::note[終了までカウント (Count to end)]
Count to end プロパティを有効にすると、実際の開始時刻にかかわらず、常に予定された終了時刻を目指してカウントダウンするように設定されます。
:::

### カスタムフィールドのインポート

Ontime は任意の数の [カスタムフィールド](/features/custom-fields/) を同時にインポートできます。 \
インポートウィザードで対応するスプレッドシートの列名を指定してください。

指定された各列について、Ontime は自動的にカスタムフィールドを作成し、スプレッドシート内の各行データをイベントに追加します。
