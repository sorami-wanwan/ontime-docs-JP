Ontime は Google スプレッドシートと双方向に同期できます。 \
複数人でのリアルタイム共同編集や、スプレッドシート上での一括データ管理に最適です。

![Spreadsheet template](../../../assets/screenshots/features/spreadsheet-template.png)
上記スクリーンショットの Google スプレッドシート テンプレートは [こちら][spreadsheet-link] から確認できます。

この機能を利用するには、Ontime に Google スプレッドシートへのアクセス権限を付与する必要があります。 \
認証完了後、Google スプレッドシートから進行表を読み込んだり書き出したりできるようになります。

:::note[前提条件]
Google スプレッドシート連携機能を利用するには、Google アカウントと Google Cloud Console へのアクセスが必要です。 \
また、Ontime が動作しているマシンがインターネットに接続されている必要があります。
:::

<Steps>
  <ol>
    <li>
      ### プロジェクトの作成
      <details>
        <summary>https://console.cloud.google.com/ にアクセスし、新しいプロジェクトを作成します</summary>
        ![step-1.1](../../../assets/screenshots/features/sheet-guide/step-1.1.jpg)
        ![step-1.2](../../../assets/screenshots/features/sheet-guide/step-1.2.jpg)
        ![step-1.3](../../../assets/screenshots/features/sheet-guide/step-1.3.jpg)
      </details>

      <details>
        <summary>作成したプロジェクトを選択します</summary>
        ![step-1.1](../../../assets/screenshots/features/sheet-guide/step-1.1.jpg)
        ![step-1.4](../../../assets/screenshots/features/sheet-guide/step-1.4.jpg)
      </details>
    </li>
    <li>
      ### Google Sheets API の有効化
      <details>
        <summary>サイドバーを開き、「APIとサービス」をクリックします</summary>
        ![step-2.00](../../../assets/screenshots/features/sheet-guide/step-2.00.jpg)
        ![step-2.01](../../../assets/screenshots/features/sheet-guide/step-2.01.jpg)
      </details>
      <details>
        <summary>「APIとサービスの有効化」をクリックします</summary>
        ![step-2.02](../../../assets/screenshots/features/sheet-guide/step-2.02.jpg)
      </details>

      <details>
        <summary>検索バーで「Sheets」を検索し、Google Sheets API を有効化します</summary>
        ![step-2.2](../../../assets/screenshots/features/sheet-guide/step-2.2.jpg)
        ![step-2.3](../../../assets/screenshots/features/sheet-guide/step-2.3.jpg)
        ![step-2.4](../../../assets/screenshots/features/sheet-guide/step-2.4.jpg)
      </details>
    </li>
    <li>
      ### データアクセスの設定（OAuth 同意画面）
      <details>
        <summary>必要なスコープを追加します</summary>
        「データアクセス」に移動し、「スコープの追加または削除」をクリックします。
        組織の設定に応じて適切に選択してください。
        ![step-3.1](../../../assets/screenshots/features/sheet-guide/step-3.1.jpg)

        「sheets」でフィルターして目的のスコープを検索します。
        ![step-3.4](../../../assets/screenshots/features/sheet-guide/step-3.4.jpg)

        「.../auth/spreadsheets」にチェックを入れ、「更新」をクリックします。
        ![step-3.5](../../../assets/screenshots/features/sheet-guide/step-3.5.jpg)
      </details>

      <details>
        <summary>保存して次へ進みます</summary>
        ![step-3.6](../../../assets/screenshots/features/sheet-guide/step-3.6.jpg)
        「テストユーザー」に、連携に使用する Google アカウントのメールアドレスを追加します。 \
        保存してダッシュボードに戻ります。
      </details>

      <details>
        <summary>テストユーザーの追加</summary>
        「対象ユーザー」に移動し、「ユーザーの追加」をクリックします。 \
        使用するメールアドレスを追加し、保存します。
        ![step-3.7](../../../assets/screenshots/features/sheet-guide/step-3.7.jpg)
      </details>
    </li>
    <li>
      ### 認証情報（クライアントシークレット）の作成
      <details>
        <summary>「認証情報」に移動します</summary>
        ![step-4.1](../../../assets/screenshots/features/sheet-guide/step-4.1.jpg)
      </details>

      <details>
        <summary>「認証情報を作成」から「OAuth クライアント ID」をクリックします</summary>
        ![step-4.2](../../../assets/screenshots/features/sheet-guide/step-4.2.jpg)
      </details>

      <details>
        <summary>アプリケーションの種類で「テレビと入力が制限されたデバイス」を選択し、名前を入力して「作成」をクリックします</summary>
        ![step-4.3](../../../assets/screenshots/features/sheet-guide/step-4.3.jpg)
      </details>

      <details>
        <summary>生成された JSON ファイル（client_secret.json）をダウンロードします。これで Google Console 側の設定は完了です</summary>
        ![step-4.5](../../../assets/screenshots/features/sheet-guide/step-4.5.jpg)
      </details>
    </li>
    <li>
      ### Ontime との接続
      <details>
        <summary>Ontime の Google スプレッドシート同期設定画面を開きます</summary>
        ![step-5.1](../../../assets/screenshots/features/sheet-guide/step-5.1.jpg)
        ![step-5.2](../../../assets/screenshots/features/sheet-guide/step-5.2.jpg)
        ![step-5.3](../../../assets/screenshots/features/sheet-guide/step-5.3.jpg)
      </details>

      <details>
        <summary>Google Cloud Console からダウンロードした client_secret.json ファイルをアップロードします</summary>
        ![step-5.4](../../../assets/screenshots/features/sheet-guide/step-5.4.jpg)
      </details>

      <details>
        <summary>対象の Google スプレッドシートの URL からシート ID をコピーして Ontime に貼り付け、「接続」をクリックします</summary>
        ![step-5.5](../../../assets/screenshots/features/sheet-guide/step-5.5.jpg)
        ![step-5.6](../../../assets/screenshots/features/sheet-guide/step-5.6.jpg)
      </details>

      <details>
        <summary>表示された認証コードをコピーし、「認証」をクリックしてブラウザで Google の認証フローを完了します</summary>
        ![step-5.7](../../../assets/screenshots/features/sheet-guide/step-5.7.jpg)
      </details>
    </li>

  </ol>
</Steps>
