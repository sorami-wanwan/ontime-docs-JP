AUXタイマー（Auxiliary timer / 補助タイマー）は、進行表の再生とは独立して並行して自由にカウント・計測できる時計機能です。 \
進行表自体のスケジュールには影響を与えず、以下のような任意の計測を行うのに便利です：
- 特定セグメントの経過時間の測定
- 動画・メディア再生の残り時間のカウントダウン

![Ontime](../../../assets/screenshots/features/aux-timer.png)

### AUXタイマーの制御
AUXタイマーは [エディタ画面](/interface/production/app-editor/) または各種 API（[HTTP](/api/protocols/http/#auxタイマー補助タイマー)、[OSC](/api/protocols/osc/#auxタイマー補助タイマー)、[WebSockets](/api/protocols/websockets/#auxタイマー補助タイマー) のドキュメントを参照）から制御できます。

### ステージタイマー画面への表示
さらに、AUXタイマーは [ステージタイマー画面](/interface/automated/stage-timer/) のサブフィールド（セカンダリ表示）として登壇者モニターに表示させることも可能です。

この設定は [エディタ画面](/interface/production/app-editor/) または各種 API（[HTTP](/api/protocols/http/#例-ステージタイマー画面のセカンダリソース切り替え)、[OSC](/api/protocols/osc/#例-ステージタイマー画面のセカンダリソース切り替え)、[WebSockets](/api/protocols/websockets/#例-ステージタイマー画面のセカンダリソース切り替え) のドキュメントを参照）から行えます。
