Ontime は進行表データをネットワーク上にブロードキャスト（配信）しており、ネットワーク上のあらゆるデバイスから利用できます。

この仕組みを活用して、タイマーの計測や配信は Ontime に任せつつ、自社のイベントや演出要件に完全に合わせた独自のカスタムビューや操作インターフェースを自由に作成できます。

## カスタムビューの作成方法
カスタムビューはお好みのテクノロジーで開発できます。Ontime のサーバー機能を使って配信する場合は、JavaScript、CSS、HTML を使用します。

基本的には、Ontime の WebSocket ストリームを受信（リッスン）し、受信したデータに応じて画面をリアルタイム更新する Web ページを作成します。

Ontime には開発の足がかりとして使えるデモページが同梱されています。接続方法やデータセットの扱い方が分かりやすく解説されています。

```bash
https://cloud.getontime.no/my-stage/external/demo
```

![Ontime](../../../assets/screenshots/features/external.png)

デモのソースコードは [GitHub リポジトリ内](https://github.com/cpvalente/ontime/tree/master/apps/server/src/external/demo) で確認できます。 \
受信できるデータ構造については [ランタイムデータのドキュメント](/api/data/runtime-data/) を参照してください。 \
画面から Ontime を遠隔制御したい場合は、[WebSocket API ドキュメント](/api/protocols/websockets/) をご覧ください。

また、WebSocket が使用できない環境向けに、HTTP ポーリング用の [API エンドポイント](/api/) も提供されています。

## カスタムビューの配信
作成したカスタムビューは、Ontime の内蔵 Web サーバー機能を使ってそのままネットワーク上に配信できます。

Ontime は、サーバーの `external` フォルダ内にあるファイルをネットワーク上に公開します。 \
例えば以下のようなフォルダ構成の場合、デモ画面は `http://<IPアドレス:ポート番号>/external/demo` からアクセスできます。

<FileTree>
- external
  - demo
    - index.html
    - styles.css
    - app.js
</FileTree>

Ontime の設定画面（`設定` -> `カスタムビュー`）から zip ファイルまたは HTML ファイルをアップロードして手軽に追加することも可能です。
