HTTP プロトコルを使用して、Ontime のほとんどの再生機能と設定を制御できます。 \
外部ソフトウェア（[vMix など](/quick-tips/integrate-with-vmix/)）やハードウェアコントローラーとの連携に最適です。

:::note[リクエストに関する仕様]
Ontime の制御用 HTTP エンドポイントは、サードパーティ機器との連携を容易にするためすべて **GET** リクエストで設計されています。 \
接続先の IP アドレスとポート番号は、お使いのネットワーク環境に合わせて設定してください。

操作が成功した場合、HTTP ステータスコード 200 番台が返されます。
:::

:::tip[実際のコードを確認する]
新機能の追加に伴い最新の API 実装を確認したい場合は、以下のソースコードリポジトリをご参照ください：
- [Ontime からのデータ取得 (api-data)](https://github.com/cpvalente/ontime/tree/master/apps/server/src/api-data)
- [Ontime の外部制御 (api-integration)](https://github.com/cpvalente/ontime/tree/master/apps/server/src/api-integration)
:::

## 状態の取得 (State)
Ontime の現在の状態を問い合わせるエンドポイントです。

### Ontime バージョンの取得
**リクエスト** 
```bash
GET <localhost:4001>/api/version
```

**レスポンス**
```ts
{"payload":"4.0.0"}
```

### ランタイム状態の取得 (ポーリング)
**リクエスト** 
```bash
GET <localhost:4001>/api/poll
```

**レスポンス** \
レスポンスには [ランタイムデータオブジェクト](/api/data/runtime-data/) が返されます。
```ts
{"payload": <runtime-data>}
```

### Ontime プロジェクトデータの取得

HTTP API を使って、アプリケーションデータの取得も可能です。

| エンドポイント                                 | 説明                                                         |
| :--------------------------------------------- | :----------------------------------------------------------- |
| `GET <localhost:4001>/data/automations`        | 登録されている [オートメーション](/api/automation/) を取得   |
| `GET <localhost:4001>/data/custom-fields`      | 登録されている [カスタムフィールド](/features/custom-fields/) を取得 |
| `GET <localhost:4001>/data/db`                 | 現在読み込まれているプロジェクトファイル全体を取得           |
| `GET <localhost:4001>/data/project`            | 現在のプロジェクトデータを取得                               |
| `GET <localhost:4001>/data/report`             | 現在のセッションレポートを取得                               |
| `GET <localhost:4001>/data/rundowns`           | プロジェクト内の全進行表を取得                               |
| `GET <localhost:4001>/data/rundowns/current`   | 現在の進行表を取得                                           |
| `GET <localhost:4001>/data/session`            | 現在のセッション統計情報を取得                               |
| `GET <localhost:4001>/data/settings`           | アプリケーションの一般設定を取得                             |
| `GET <localhost:4001>/data/url-presets`        | 登録されている [URLプリセット](/features/url-presets/) を取得 |
| `GET <localhost:4001>/data/view-settings`      | ビュー設定を取得                                             |

## イベントの変更 (Change event)
```bash
GET <localhost:4001>/api/change/<event-id>/<property>/<value>
```

change エンドポイントを使用すると、指定したイベントの各プロパティ（下記）を変更できます。

| プロパティ名  | 値の型 / 設定値                                                                                          |
| :------------ | :-------------------------------------------------------------------------------------------------------- |
| `title`       | 文字列 (string)                                                                                          |
| `note`        | 文字列 (string)                                                                                          |
| `cue`         | 文字列 (string: 8文字以内を推奨)                                                                         |
| `skip`        | 真偽値 (boolean)                                                                                          |
| `colour`      | 文字列 (#16進数カラーコード または [CSSカラー名](https://developer.mozilla.org/en-US/docs/Web/CSS/named-color)) |
| `custom`      | `custom:<フィールド名>` で特定のカスタムフィールドを指定                                                 |
| `timeWarning` | 数値 (ミリ秒)                                                                                            |
| `timeDanger`  | 数値 (ミリ秒)                                                                                            |
| `endAction`   | 文字列 (`none` / `load-next` / `play-next`)                                                              |
| `timerType`   | 文字列 (`count-down` / `count-up` / `clock` / `none`)                                                     |
| `duration`    | 数値 (ミリ秒)                                                                                            |
| `timeStart`   | 数値 (ミリ秒)                                                                                            |
| `timeEnd`     | 数値 (ミリ秒)                                                                                            |

:::caution[注意]
`skip`、`endAction`、`duration`、`timeStart`、`timeEnd` の各プロパティを変更すると、進行表全体の再計算が行われるため、連続した大量書き込みにはスロットリング（流量制限）が適用されます。
:::

### 例: イベントタイトルの変更
**リクエスト**
```bash
GET <localhost:4001>/api/change/<my-event-id>?title=new-title
```
**レスポンス**
```ts
{"payload":"success"}
```

### 例: カスタムフィールドの変更
カスタムフィールドを変更するには、事前にプロジェクト設定でそのフィールドが作成されている必要があります。

**リクエスト**
```bash
GET <localhost:4001>/api/change/<my-event-id>?custom:<field-name>=new-value
```
**レスポンス**
```ts
{"payload":"success"}
```

### 例: 複数フィールドの同時変更
クエリパラメーターを連結することで、1回のリクエストで複数フィールドを変更できます。

**リクエスト**
```bash
GET <localhost:4001>/api/change/<my-event-id>?title=new-title&cue=new-cue
```
**レスポンス**
```ts
{"payload":"success"}
```

## メッセージの制御 (Message)

### 例: セカンダリメッセージ（サブメッセージ）のテキスト変更
**リクエスト**
```bash
GET <localhost:4001>/api/message/secondary/new text
```

**レスポンス**
```ts
{
    "payload": {
        "secondary": "new text",
        "timer": {
            "text": "",
            "visible": true,
            "blink": false,
            "blackout": false,
            "secondarySource": null
        },
    }
}
```

### 例: ステージタイマー画面のセカンダリソース切り替え
**リクエスト**
```bash title="AUXタイマーをサブフィールドに表示"
GET <localhost:4001>/api/message/timer?secondarySource=aux
```

**リクエスト**
```bash title="セカンダリメッセージをサブフィールドに表示"
GET <localhost:4001>/api/message/timer?secondarySource=secondary
```

**リクエスト**
```bash title="サブフィールドを非表示にする"
# ※`aux` または `secondary` 以外の値を送ると非表示（null）になります
GET <localhost:4001>/api/message/timer?secondarySource=off
```

**レスポンス**
```ts
{
    "payload": {
        "secondary": "new text",
        "timer": {
            "text": "",
            "visible": true,
            "blink": false,
            "blackout": false,
            "secondarySource": "secondary"
        },
    }
}
```

### 例: タイマー画面のブラックアウト（暗転）
**リクエスト**
```bash title="タイマー画面をブラックアウト"
GET <localhost:4001>/api/message/timer?blackout=true
```

**リクエスト**
```bash title="ブラックアウトを解除"
GET <localhost:4001>/api/message/timer?blackout=false
```

**レスポンス**
```ts
{
    "payload": {
        "secondary": "",
        "timer": {
            "text": "",
            "visible": true,
            "blink": true,
            "blackout": false,
            "secondarySource": null
        },
    }
}
```

## AUXタイマー（補助タイマー）

進行表の再生に影響を与えない [AUXタイマー](/features/aux-timer/) を HTTP から制御できます。

### AUXタイマーの設定時間を設定
**リクエスト**
```bash
GET <localhost:4001>/api/auxtimer/1/duration/<ミリ秒単位の値>
```

### AUXタイマーのカウント方向を設定
カウントアップまたはカウントダウンを指定します。

#### カウントアップに設定
**リクエスト**
```bash
GET <localhost:4001>/api/auxtimer/1/direction/count-up
```

#### カウントダウンに設定
**リクエスト**
```bash
GET <localhost:4001>/api/auxtimer/1/direction/count-down
```

### AUXタイマーの開始
**リクエスト**
```bash
GET <localhost:4001>/api/auxtimer/1/start
```

### AUXタイマーの一時停止
**リクエスト**
```bash
GET <localhost:4001>/api/auxtimer/1/pause
```

### AUXタイマーの停止
**リクエスト**
```bash
GET <localhost:4001>/api/auxtimer/1/stop
```

### AUXタイマーへの時間追加・短縮
**リクエスト**
```bash
GET <localhost:4001>/api/auxtimer/1/addtime/<ミリ秒単位の値>
```
