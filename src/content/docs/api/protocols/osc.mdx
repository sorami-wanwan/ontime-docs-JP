OSC および WebSocket API を使用すると、Ontime サーバーと極めて低いレイテンシーで通信できます。

:::note[OSC の設定]
OSC API を利用するには、`エディタ` -> `設定` -> `オートメーション` で OSC 機能を有効化し、受信ポート（デフォルト: 8888）を設定する必要があります。

OSC プロトコルの性質上、Ontime からの状態フィードバックを受け取るには、オートメーション機能を使って Ontime と外部機器の双方でメッセージ送受信設定を行う必要があります。

受信した OSC メッセージは、`エディタ` -> `ネットワーク` -> `イベントログ` の **ネットワークログ** でリアルタイムに監視できます。
:::

## イベントの変更 (Change event)
```bash
/ontime/change/<event-id>/<field> <new-value>
```

change エンドポイントを使用すると、指定したイベントの各プロパティ（下記）を変更できます。 \
変更対象のイベント ID と、変更したいフィールド名を指定して送信します。

| プロパティ名  | 値の型 / 設定値                                                                                          |
| :------------ | :-------------------------------------------------------------------------------------------------------- |
| `title`       | 文字列 (string)                                                                                          |
| `note`        | 文字列 (string)                                                                                          |
| `cue`         | 文字列 (string: 8文字以内を推奨)                                                                         |
| `skip`        | 真偽値 (boolean)                                                                                          |
| `colour`      | 文字列 (#16進数カラーコード または [CSSカラー名](https://developer.mozilla.org/en-US/docs/Web/CSS/named-color)) |
| `custom`      | `custom:<フィールド名>` で特定のカスタムフィールドを指定                                                 |
| `timeWarning` | 数値 (ミリ秒)                                                                                            |
| `timeDanger`  | 数値 (ミリ秒)                                                                                            |
| `endAction`   | 文字列 (`none` / `load-next` / `play-next`)                                                              |
| `timerType`   | 文字列 (`count-down` / `count-up` / `clock` / `none`)                                                     |
| `duration`    | 数値 (ミリ秒)                                                                                            |
| `timeStart`   | 数値 (ミリ秒)                                                                                            |
| `timeEnd`     | 数値 (ミリ秒)                                                                                            |

:::caution[注意]
`skip`、`endAction`、`duration`、`timeStart`、`timeEnd` の各プロパティを変更すると、進行表全体の再計算が行われるため、連続した大量書き込みにはスロットリング（流量制限）が適用されます。
:::

### 例: イベントタイトルの変更
**OSC メッセージ**
```bash
/ontime/change/<event-id>/title <new-value>
```

### 例: カスタムフィールドの変更
カスタムフィールドを変更するには、事前にプロジェクト設定でそのフィールドが作成されている必要があります。 \
詳しくは [カスタムフィールド](/features/custom-fields/) をご覧ください。

**OSC メッセージ**
```bash
/ontime/change/<event-id>/custom:<field-name> <new-value>
```

## メッセージの制御 (Message)
ステージタイマー画面に表示するメッセージを制御するエンドポイントです。

### 例: セカンダリメッセージ（サブメッセージ）のテキスト変更

**OSC メッセージ**
```bash
# ※テキストのみを設定します。表示の切り替えは別操作となります（下記参照）。
/ontime/message/secondary <new-text>
```

### 例: ステージタイマー画面のセカンダリソース切り替え
**OSC メッセージ**
```bash title="AUXタイマーをサブフィールドに表示"
/ontime/message/timer/secondarySource 'aux'
```

**OSC メッセージ**
```bash title="セカンダリメッセージをサブフィールドに表示"
/ontime/message/timer/secondarySource 'secondary'
```

**OSC メッセージ**
```bash title="サブフィールドを非表示にする"
# ※`aux` または `secondary` 以外の値を送ると非表示（null）になります
/ontime/message/timer/secondarySource 'off'
```

### 例: タイマー画面のブラックアウト（暗転）
ステージタイマー画面全体を一括で暗転（ブラックアウト）させることができます。

**OSC メッセージ**
```bash title="タイマー画面をブラックアウト"
/ontime/message/timer/blackout true
```

**OSC メッセージ**
```bash title="ブラックアウトを解除"
/ontime/message/timer/blackout false
```

## プレイバック制御 (Playback)
Ontime の再生、停止、一時停止などの再生動作を制御します。

## イベントの再生開始 (Start)

### ロード中のイベントを開始
**OSC メッセージ**
```bash
/ontime/start
```

### 指定インデックスのイベントを開始
**OSC メッセージ**
```bash
/ontime/start/index <event-index>
```

### 指定 ID のイベントを開始
**OSC メッセージ**
```bash
/ontime/start/id <event-id>
```

### 指定キューのイベントを開始
**OSC メッセージ**
```bash
/ontime/start/cue <event-cue>
```

### 次のイベントを開始
**OSC メッセージ**
```bash
/ontime/start/next
```

### 前のイベントを開始
**OSC メッセージ**
```bash
/ontime/start/previous
```

## タイマーの一時停止 (Pause)
**OSC メッセージ**
```bash
/ontime/pause
```

**OSC メッセージ**
```bash

```

**OSC メッセージ**


## 手動での時間追加・短縮 (Add/Remove Time)
### 時間を追加
**OSC メッセージ**
```bash
/ontime/addtime/add <ミリ秒単位の値>
```

### 時間を短縮
**OSC メッセージ**
```bash
/ontime/addtime/remove <ミリ秒単位の値>
```

## AUXタイマー（補助タイマー）

進行表の再生に影響を与えない [AUXタイマー](/features/aux-timer/) を OSC から制御できます。

### AUXタイマーの設定時間を設定
**OSC メッセージ**
```bash
/ontime/auxtimer/1/duration <ミリ秒単位の値>
```

### AUXタイマーのカウント方向を設定
カウントアップまたはカウントダウンを指定します。

#### カウントアップに設定
**OSC メッセージ**
```bash
/ontime/auxtimer/1/direction count-up
```

#### カウントダウンに設定
**OSC メッセージ**
```bash
/ontime/auxtimer/1/direction count-down
```

### AUXタイマーの開始
**OSC メッセージ**
```bash
/ontime/auxtimer/1/start
```

### AUXタイマーの一時停止
**OSC メッセージ**
```bash
/ontime/auxtimer/1/pause
```

### AUXタイマーの停止
**OSC メッセージ**
```bash
/ontime/auxtimer/1/stop
```

### AUXタイマーへの時間追加・短縮
**OSC メッセージ**
```bash
/ontime/auxtimer/1/addtime <ミリ秒単位の値>
```
