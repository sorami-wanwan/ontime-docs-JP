WebSocket API を使用すると、Ontime サーバーと双方向かつ極めて低レイテンシーで通信できます。

WebSocket サーバーはメインアプリケーションと同じ IP アドレスおよびポートで動作します：
```bash
ws://<IPアドレス>:<ポート番号>/ws
```

:::note
Ontime に接続したすべての WebSocket クライアントは、接続時に [ランタイムデータ](/api/data/runtime-data/) で定義されている現在のアプリケーション状態のスナップショットを受信します。
:::

## 状態の取得 (State)

### Ontime バージョンの取得
**リクエスト** 
```bash
Target: ws://<IPアドレス>:<ポート番号>/ws
Message: {"tag": "version"}
```

**レスポンス**
```ts
{"tag":"version","payload":"4.0.0"}
```

### ランタイム状態の取得 (ポーリング)
**リクエスト**
```bash
Target: ws://<IPアドレス>:<ポート番号>/ws
Message: {"tag": "poll"}
```

**レスポンス** \
レスポンスには [ランタイムデータオブジェクト](/api/data/runtime-data/) が返されます。
```ts
{
    "tag": "poll", 
    "payload": <runtime-data>
}
```

## イベントの変更 (Change event)

change エンドポイントを使用すると、指定したイベントの各プロパティ（下記）を変更できます。

| プロパティ名  | 値の型 / 設定値                                                                                          |
| :------------ | :-------------------------------------------------------------------------------------------------------- |
| `title`       | 文字列 (string)                                                                                          |
| `note`        | 文字列 (string)                                                                                          |
| `cue`         | 文字列 (string: 8文字以内を推奨)                                                                         |
| `skip`        | 真偽値 (boolean)                                                                                          |
| `colour`      | 文字列 (#16進数カラーコード または [CSSカラー名](https://developer.mozilla.org/en-US/docs/Web/CSS/named-color)) |
| `custom`      | `custom:<フィールド名>` で特定のカスタムフィールドを指定                                                 |
| `timeWarning` | 数値 (ミリ秒)                                                                                            |
| `timeDanger`  | 数値 (ミリ秒)                                                                                            |
| `endAction`   | 文字列 (`none` / `load-next` / `play-next`)                                                              |
| `timerType`   | 文字列 (`count-down` / `count-up` / `clock` / `none`)                                                     |
| `duration`    | 数値 (ミリ秒)                                                                                            |
| `timeStart`   | 数値 (ミリ秒)                                                                                            |
| `timeEnd`     | 数値 (ミリ秒)                                                                                            |

:::caution[注意]
`skip`、`endAction`、`duration`、`timeStart`、`timeEnd` の各プロパティを変更すると、進行表全体の再計算が行われるため、連続した大量書き込みにはスロットリング（流量制限）が適用されます。
:::

### 例: イベントタイトルの変更
**リクエスト**
```bash
Target: ws://<IPアドレス>:<ポート番号>/ws
Message: {
    "tag": "change", 
    "payload": {
        "<event-id>": {
            "title": "新しいタイトル"
        }
    }
}
```

**レスポンス**
```ts
{
  "tag": "change",
  "payload": {
    "<event-id>": {
      "title": "新しいタイトル"
    }
  }
}
```

### 例: カスタムフィールドの変更
カスタムフィールドを変更するには、事前にプロジェクト設定でそのフィールドが作成されている必要があります。

**リクエスト**
```bash
Target: ws://<IPアドレス>:<ポート番号>/ws
Message: {
    "tag": "change", 
    "payload": {
        "<event-id>": {
            "custom:<field-name>": "新しい値"
        }
    }
}
```
**レスポンス**
```ts
{
  "tag": "change",
  "payload": {
    "<event-id>": {
      "custom:<field-name>": "新しい値"
    }
  }
}
```

## メッセージの制御 (Message)

### 例: セカンダリメッセージ（サブメッセージ）のテキスト変更
**リクエスト**
```bash
Target: ws://<IPアドレス>:<ポート番号>/ws
Message: {
    "tag": "message", 
    "payload": {
        "secondary": "新しいメッセージ"
    }
}
```

**レスポンス**
```ts
{
    "tag":"message",
    "payload": {
        "secondary": "新しいメッセージ",
        "timer": {
            "text": "",
            "visible": true,
            "blink": false,
            "blackout": false,
            "secondarySource": null
        },
    }
}
```

### 例: ステージタイマー画面のセカンダリソース切り替え
**リクエスト**
```bash title="AUXタイマーをサブフィールドに表示"
Target: ws://<IPアドレス>:<ポート番号>/ws
Message: {
    "tag": "message", 
    "payload": {
        "timer": {
            "secondarySource": "aux"
        }
    }
}
```

**リクエスト**
```bash title="セカンダリメッセージをサブフィールドに表示"
Target: ws://<IPアドレス>:<ポート番号>/ws
Message: {
    "tag": "message", 
    "payload": {
        "timer": {
            "secondarySource": "secondary"
        }
    }
}
```

**リクエスト**
```bash title="サブフィールドを非表示にする"
# ※`aux` または `secondary` 以外の値を送ると非表示（null）になります
Target: ws://<IPアドレス>:<ポート番号>/ws
Message: {
    "tag": "message", 
    "payload": {
        "timer": {
            "secondarySource": null
        }
    }
}
```

**レスポンス**
```ts
{
    "payload": {
        "secondary": "新しいメッセージ",
        "timer": {
            "text": "",
            "visible": true,
            "blink": false,
            "blackout": false,
            "secondarySource": "secondary"
        },
    }
}
```

### 例: タイマー画面のブラックアウト（暗転）
**リクエスト**
```bash title="タイマー画面をブラックアウト"
Target: ws://<IPアドレス>:<ポート番号>/ws
Message: {
    "tag": "message", 
    "payload": {
        "timer": {
            "blackout": true
        }
    }
}
```

**リクエスト**
```bash title="ブラックアウトを解除"
Target: ws://<IPアドレス>:<ポート番号>/ws
Message: {
    "tag": "message", 
    "payload": {
        "timer": {
            "blackout": false
        }
    }
}
```

**レスポンス**
```ts
{
    "payload": {
        "secondary": "",
        "timer": {
            "text": "",
            "visible": true,
            "blink": true,
            "blackout": false,
            "secondarySource": null
        },
    }
}
```

## イベントの再生開始 (Start)

### ロード中のイベントを開始
**リクエスト**
```bash
Target: ws://<IPアドレス>:<ポート番号>/ws
Message: {"tag": "start"}
```

### 指定インデックスのイベントを開始
**リクエスト**
```bash
Target: ws://<IPアドレス>:<ポート番号>/ws
Message: {
    "tag": "start", 
    "payload": {
        "index": 1
    }
}
```

### 指定 ID のイベントを開始
**リクエスト**
```bash
Target: ws://<IPアドレス>:<ポート番号>/ws
Message: {
    "tag": "start", 
    "payload": {
        "id": "<event-id>"
    }
}
```

### 指定キューのイベントを開始
**リクエスト**
```bash
Target: ws://<IPアドレス>:<ポート番号>/ws
Message: {
    "tag": "start", 
    "payload": {
        "cue": "<event-cue>"
    }
}
```

### 次のイベントを開始
**リクエスト**
```bash
Target: ws://<IPアドレス>:<ポート番号>/ws
Message: {
  "tag": "start",    
  "payload": "next"
}
```

### 前のイベントを開始
**リクエスト**
```bash
Target: ws://<IPアドレス>:<ポート番号>/ws
Message: {
  "tag": "start",    
  "payload": "previous"
}
```

## AUXタイマー（補助タイマー）

進行表の再生に影響を与えない [AUXタイマー](/features/aux-timer/) を WebSocket から制御できます。

### AUXタイマーの設定時間を設定
**リクエスト**
```bash
Target: ws://<IPアドレス>:<ポート番号>/ws
Message: {
    "tag": "auxtimer",
    "payload": {
        "1": {
            "duration": <ミリ秒単位の値>
        }
    }
}
```

### AUXタイマーのカウント方向を設定
カウントアップまたはカウントダウンを指定します。

#### カウントアップに設定
**リクエスト**
```bash
Target: ws://<IPアドレス>:<ポート番号>/ws
Message: {
    "tag": "auxtimer",
    "payload": {
        "1": {
            "duration": "count-up"
        }
    }
}
```

#### カウントダウンに設定
**リクエスト**
```bash
Target: ws://<IPアドレス>:<ポート番号>/ws
Message: {
    "tag": "auxtimer",
    "payload": {
        "1": {
            "duration": "count-down"
        }
    }
}
```

### AUXタイマーの開始
**リクエスト**
```bash
Target: ws://<IPアドレス>:<ポート番号>/ws
Message: {
    "tag": "auxtimer",
    "payload": {
```
