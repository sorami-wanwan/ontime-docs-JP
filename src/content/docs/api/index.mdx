Ontime のデータは大きく分けて以下の 2 種類に分類されます：

#### プロジェクトデータ (Project data)
アプリを終了・再起動しても保持される永続的な設定や進行表データです。 \
変更頻度は比較的低く、主に HTTP エンドポイント経由で送受信されます。

#### ランタイムデータ (Runtime data)
ユーザーの操作やタイマーの進行によってリアルタイムに変化するデータ（タイマー値、再生状態、オフセットなど）です。 \
非常に高い頻度で更新され、WebSocket でストリーミング配信されるほか、サポートされているすべてのプロトコル（OSC、WebSocket、HTTP）で取得・変更が可能です。

## プロジェクトデータの取得
プロジェクトデータを取得するための HTTP エンドポイントについては、[プロジェクトデータのドキュメント](/api/data/project-data/) を参照してください。

## 外部からの Ontime 制御
OSC、WebSocket、HTTP の各 API を使用して、Ontime サーバーと低レイテンシーで通信・制御できます。 \
プロトコル間の機能差はほとんどないため、利用する外部機器や制作環境（vMix、Qlab、disguise、OBS、TouchDesigner など）に合わせて最適なプロトコルを選択できます。

各プロトコルの詳細ドキュメント：
- [OSC API](/api/protocols/osc/)
- [WebSocket API](/api/protocols/websockets/)
- [HTTP API](/api/protocols/http/)

## Ontime からの外部制御（オートメーション）
Ontime の **オートメーション機能** を使用して、Ontime のランタイムデータを外部システムに送信したり、イベントの進行に合わせて他のソフトウェア・照明・音響機器を自動制御したりできます。 \
詳しくは [オートメーション機能のドキュメント](/api/automation/) をご覧ください。
