## 進行表 (Rundown)

以下のエンドポイントを使用すると、現在読み込まれているプロジェクトの進行表に対するデータ操作が可能です。

:::tip[実際のコードを確認する]
新機能の追加に伴いドキュメントが更新されるまでの間、最新のルーター実装は [GitHub 上のコード (rundown.router.ts)](https://github.com/cpvalente/ontime/blob/master/apps/server/src/api-data/rundown/rundown.router.ts) で確認できます。
:::

### GET Rundown (進行表の取得)

進行表全体のデータを取得します。

**リクエスト**

```bash
GET <localhost:4001>/data/rundown/current
```

**レスポンス**

```ts
200: {
  id: RundownId;
  title: string;
  order: EntryId[];
  flatOrder: EntryId[];
  entries: RundownEntries;
  revision: number;
}
```

### POST Entry (エントリの追加)

進行表に新しいエントリを追加します。

**リクエスト**

```bash
POST <localhost:4001>/data/rundown/:rundownId/entry
```

**リクエストボディ**

リクエストボディには [Ontime イベントデータ](/api/data/event-data/) のプロパティを指定します（すべて任意）。

また、`after` プロパティに挿入位置の直前となるイベント ID を指定できます。 \
`after` を省略した場合は進行表の末尾に追加されます。

```
| プロパティ           | 設定値                                    |
| -------------------- | ----------------------------------------- |
| type                 | "event" | "delay" | "group" | "milestone" |
| after                | Optional<string>                          |
```

**レスポンス**

```ts
201: {OntimeEntry}
```

### PUT Event (イベントの更新)

既存のイベントの内容を部分更新（パッチ）します。

**リクエスト**

```bash
PUT <localhost:4001>/data/rundown/:rundownId/:entryId
```

**リクエストボディ**

イベント ID と更新したい [Ontime イベントデータ](/api/data/event-data/) のプロパティを含むオブジェクトを送信します。

すべてのプロパティは任意（指定したフィールドのみ更新）です。

```
| プロパティ           | 設定値                      |
| -------------------- | --------------------------- |
| id                   | Required<string>            |
```

**レスポンス**

更新後のイベントデータが返されます。

```ts
200: {OntimeEntry}
```

### DELETE Event (イベントの削除)

指定した ID のイベントを進行表から削除します。

**リクエスト**

```bash
DELETE <localhost:4001>/data/rundown/:rundownId/:entryId
```

**リクエストボディ**

```
| パラメーター         | 設定値               |
| -------------------- | -------------------- |
| ids                  | Required<string[]>   |
```

**レスポンス**

```ts
204: {message: 'Events deleted'}
```
