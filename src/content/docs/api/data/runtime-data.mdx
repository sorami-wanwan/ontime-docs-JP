---
title: ランタイムデータ (Runtime Data)
description: Ontime のリアルタイム実行データ
---

Ontime は現在の状態を WebSocket 経由でリアルタイムにブロードキャスト（配信）しています。 \
これにより、外部システムやカスタムビューがアプリケーションの状態とミリ秒単位で同期できます。

Ontime が保持するランタイムデータの全体構造は以下の通りです。 \
このデータ構造は [オートメーション機能での変数指定](/api/automation/#オートメーションでの変数の使用) でも使用されます。

:::tip[実際の型定義を確認する]
新機能の追加に伴いドキュメントが更新されるまでの間、最新の型定義は [ソースコード上の RuntimeStore.type.ts](https://github.com/cpvalente/ontime/blob/master/packages/types/src/definitions/runtime/RuntimeStore.type.ts) および [初期ステート定義](https://github.com/cpvalente/ontime/blob/master/apps/client/src/common/stores/runtime.ts) で直接確認できます。
:::

:::note
Ontime が配信するメッセージは以下のような形式です。 \
`type` にメッセージ種別（`ontime`）が入り、`payload` に [ランタイムデータオブジェクト](#ランタイムデータオブジェクト) が含まれます。

```ts
// Ontime からのブロードキャストメッセージ例
{ type: "ontime", payload: "<runtime-data-object>"}
```

通信効率を高めるため、Ontime は変更された個別オブジェクトのみを小さな差分メッセージとしても配信します：
```ts
// 変更されたサブセットのみを更新する個別メッセージ
{ type: "ontime-timer", payload: "<runtime-data-object>.timer"}
{ type: "ontime-offset", payload: "<runtime-data-object>.offset"}
{ type: "ontime-eventNow", payload: "<runtime-data-object>.eventNow"}
...
```
:::

## ランタイムデータオブジェクト

:::note
すべての時刻・時間は午前0時からの **ミリ秒 (ms)** で表現されます。
:::

### ontime-clock
サーバーの現在時刻（システムクロック）を保持します。
```ts
{
  clock: number
}
```

### ontime-timer
アプリケーションのタイマーに関するデータを保持します。
```ts
{
  addedTime: number                                         // ユーザーによって追加/短縮された時間
  current: number | null                                    // 実行中のカウントダウン値
  duration: null                                            // ロード中イベントの所要時間
  elapsed: null                                             // 現在のタイマーの経過時間
  playback: 'play' | 'pause' | 'armed' | 'stop' | 'roll'    // プレイバック再生状態
  startedAt: number | null                                  // タイマーが開始された時刻
  expectedFinish: number | null                             // タイマーが終了する見込み時刻
  finishedAt: number | null                                 // タイマーが0に到達した時刻
}
```

### ontime-message
メッセージ機能に関するデータを保持します。2つのメッセージオブジェクトを含みます：
[ステージタイマー画面](/interface/automated/stage-timer/) へのメッセージ表示状態と、[セカンダリメッセージ（サブメッセージ）](/features/secondary-message/) のデータです。

```ts
timer: {
  text: string
  visible: boolean
  blink: boolean
  blackout: boolean
  secondarySource: 'aux1' | 'aux2' | 'aux3' | 'secondary' | null
}
secondary: string
```

### ontime-rundown
進行表（ランダウン）全体に関するデータを保持します。
```ts
{
  numEvents: number                                             // 進行表内のイベント総数
  selectedEventIndex: number | null                             // 選択中イベントのインデックス
  plannedStart: number                                          // 進行表の開始予定時刻
  plannedEnd: number | null                                     // 進行表の終了予定時刻
  actualStart: number | null                                    // 進行表の実際の開始時刻
  currentDay: number | null                                     // 日付またぎ計算用の内部フラグ
  actualGroupStart: number | null                               // 現在グループの実際の開始時刻
  offset: number | null                                         // スケジュールとの現在の遅延・進み差分
  expectedEnd: number | null                                    // 進行表全体の終了見込み時刻
}
```

### ontime-offset
進行表の遅延（オフセット）に関するデータを保持します。
```ts
{
  absolute: number                                              // 予定時刻を基準としたオフセット
  relative: number                                              // 開始後の進行のみを考慮した相対オフセット
  mode: 'absolute' | 'relative'                                 // 現在選択されているオフセットモード
  expectedGroupEnd: number | null                               // 現在グループの終了見込み時刻
  expectedRundownEnd: number | null                             // 進行表全体の終了見込み時刻
  expectedFlagStart: number | null                              // 次のフラグ付きイベントの開始見込み時刻
}
```

### ontime-auxtimer1 (2 および 3)
[AUXタイマー（補助タイマー）](/features/aux-timer/) に関するデータを保持します。
```ts
{
  duration: number                                              // AUXタイマーの設定時間
  current: number                                               // 現在のタイマー値
  playback: 'play' | 'pause' | 'stop'                           // 再生状態
  direction: 'count-down' | 'count-up'                          // カウント方向
}
```
