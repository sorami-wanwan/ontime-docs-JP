## ontime-JP（日本語フォーク版）について

<CardGrid>
  <Card title="日本語 UI に完全対応" icon="seti:html">
    エディタ、キューシート、オペレーター画面、各種タイマー画面など、すべてのインターフェースを日本語化しています。
  </Card>
  <Card title="日本語 IME 入力の最適化" icon="pencil">
    日本語入力（IME）確定時のキーショートカット誤爆を防止し、現場でのスムーズなタイピングとデータ入力を実現しています。
  </Card>
  <Card title="完全な日本語マニュアル" icon="open-book">
    全機能、各種 API（HTTP / OSC / WebSocket）、外部連携ツールの使い方を網羅した日本語ドキュメントを提供しています。
  </Card>
  <Card title="オープンソース & 自由な利用" icon="github">
    Carlos Valente 氏による公式版 [Ontime](https://github.com/cpvalente/ontime)（GPL v3）をベースにしたコミュニティフォークです。
  </Card>
</CardGrid>
